# 같은 바이옴의 초기 정적 지도 재현

이 계약은 맵 저장소 개발자 프로토타입 전용이다. 설치된 모드의 추천창·저장·Undo·Map Preview DLL에는 연결하지 않는다. 같은 바이옴의 원본을 선택했을 때 초기 지형과 실제 미리보기를 그대로 재현하고, 다른 바이옴에서는 기존의 바이옴 적응을 유지한다.

## 적용 조건

`replica_layer`가 있는 완전한 관측 레시피의 새 후보만 선택한다. 원본과 대상의 BiomeDef 이름 및 가로·세로 칸수가 같고, 제품 params가 비어 있으며, 기존 ground/water/rock/cave 네 sidecar가 모두 있어야 한다. 실제 저장 맵이나 이미 편집한 지도에 복제하기 위해 기존 건물·강·도로를 지우는 용도가 아니다.

이미 `replica_layer`가 있는 명령을 새 미편집 후보라고 확인할 수 없는 호출에는 `ValueError`로 거절한다. 비활성 영수증을 반환하면서 활성 복제 metadata를 남기는 재사용을 허용하지 않는다.

다른 바이옴 또는 크기에서는 복제 파일을 적용하지 않고 기존의 생성 경로를 유지한다. 복제 정보가 없는 core·이미지·이전 레시피도 기존 경로를 사용한다. 같은 바이옴이지만 검증에 필요한 원본 정보가 없거나 안전 검사를 통과하지 못하면 정확 재현 후보를 제외하고 이유를 기록한다. 이를 정확 재현 성공으로 표시하지 않는다.

## 실제 원본과 파일 연결

새 source manifest의 `capture_replica:true`가 원본을 실제 게임에서 생성한 뒤 `PostMapInitialized`에서 관측한다. 기존 terrain schema2·geology schema1·99999 PNG는 그대로 보존하며, 새 원본 `*-replica.json` 및 `*-replica-map.png`, `*-replica-map-default.png`는 최종 단계의 별도 산출물이다. 이전 99999 자료는 출처 해시로 묶고, 최종 raw와 이전 단계 필드의 차이는 허용한다. 최종 재현의 정답은 최종 원자료다.

`replica_layer` schema1은 source biome·width·height·snapshot 상대경로·SHA256만 담는다. 경로는 레시피 파일 기준으로 해석하며 실험 자료 경계 밖을 허용하지 않는다. 원본 raw에는 terrain/geology 및 최종 실제 PNG 두 개의 파일명과 SHA256을 기록한다. 원본 정보가 부족하면 None·0으로 추정해서 채우지 않는다. 제품 모델 JSON 크기 제한을 늘리는 변경은 아니다.

## 재현하는 상태

- 바닥의 top·영구/표면·under·foundation·임시층과 색.
- 실제 elevation·Caves·fertility의 모든 칸. 허용 오차를 만들어 원본 차이를 숨기지 않는다.
- 실제 지붕 및 보행 상태, 자연 지붕의 native 지지 여부.
- 실제 자연 암석·광석과 edifice의 정의·재료·회전·루트 좌표·고유 점유 영역·체력. 다칸 건물을 각 칸의 독립 건물로 만들지 않는다.
- 실제 Map Preview renderer의 토양 색 사용/기본 색 사용 두 PNG의 전체 RGBA 픽셀.

원본 seed·월드·타일 설정을 대상 월드에 덮어쓰는 기능이 아니다. 퀘스트·인시던트·pawn·아이템·식물의 생존/시간 상태를 보존하는 세이브 복제도 아니다. 게임을 진행하면 식생·물의 결빙·날씨 등은 대상 환경과 게임 시뮬레이션을 따른다. 원본과 다른 크기는 일대일 칸 복제 대상이 아니므로 기존 리샘플링 범위로 구분한다.

## 생성·보호·최종 검사

복제할 때는 별도의 빈 후보 지도에 원본 정적 상태를 배치한다. 대상 타일의 native scatter가 만든 폐허가 원본 바닥과 암석을 뒤늦게 덮지 않도록 이 후보의 생성 단계만 분리한다. 이미 생성된 사용자 건물을 삭제해 수치를 맞추지 않는다. 기존 일반 생성과 다른 바이옴의 native 단계는 유지한다.

시작 전 기존 Thing·지붕·레이어·제품 상태를 검사하며, 생성 도중 허용하지 않은 변경이나 누락이 생기면 실패한다. spawn의 잠재적 wiping 대상이 없어야 한다. 자연 지붕 지지 검사와 알려지지 않은 상태 검사는 그대로 유지하며, 무지지 지붕을 복제하려고 collapse를 전역으로 끄지 않는다.

생성 후에는 초기 적용 성공과 최종 map 성공을 분리한다. 후반 scenario/map component/finalization이 바꾼 상태도 최종 원본 대조에 들어간다. 구조물·unknown·보호 칸을 비교 분모에서 빼지 않는다. native 적용 영수증과 Python 독립 전체 필드/고유 건물/PNG 두 모드 대조가 모두 통과한 조건만 검증된 후보로 인정한다. PNG는 건물·지붕을 직접 그리는 완전한 상태 그림이 아니므로 그림만 같다는 근거로 배치가 동일하다고 주장하지 않는다.

## 회귀와 범위

기존 core·sidecar 없는 생성 및 다른 바이옴의 입력/실제 terrain·PNG를 보존 대조한다. 필수 필드 누락·unknown·해시 위조·지붕 위험·기존 건물·단 한 칸의 필드/픽셀 차이를 양성 거절로 확인한다. 실제 결과와 실패 원본은 새 실험 폴더에 보존하며 과거 실험을 덮어쓰지 않는다. 이번 static 재현 결과를 모든 바이옴·크기·모드 조합 또는 미관·플레이 품질의 보장으로 확대하지 않는다.
