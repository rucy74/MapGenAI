# MapGen AI — 직접 눈으로 확인하는 텍스트 테스트 80개

2026-09-14 작성. 대상: MapGen AI [DEV], 기능 기준 dev `99d648e`, RimWorld 1.6.

이 파일은 사용자가 직접 입력하고 결과를 비교하기 위한 새 테스트 문장 모음입니다. 현재 설명서·실제 요청/생성 검증 기록·지원 범위를 바탕으로 작성했으며, 아래 80문장을 모두 새로 API 호출하거나 실행한 결과표는 아닙니다. 성공 여부는 빈칸으로 남겼습니다.

## 사용 방법

1. 새 테스트 월드에서 **Harmony → Map Preview → MapGen AI [DEV]**를 활성화합니다. 기존 MapGen AI와 DEV는 한쪽만 사용합니다.
2. 기본 타일은 **250×250, 평지, 온대림, 강·해안·도로·특수 지형 특징 없음**을 우선합니다. 특수 조건이 필요한 그룹은 별도로 적었습니다. 크기나 다른 모드가 달라지면 배치 공간과 결과도 달라집니다.
3. **그룹을 바꿀 때 초기화**, 같은 그룹에서는 지정한 순서대로 한 문장씩 입력합니다. 추가 초기화/타일 변경이 필요한 곳은 각 문장에 표시했습니다. “초기화”는 AI 대화창의 초기화/Reset 기능을 뜻합니다.
4. 코드 상자 안의 문장만 복사합니다. 각 응답과 미리보기가 끝난 뒤 다음 문장을 입력합니다. 앞선 단계가 실패하면 이후 단계의 “그 호수/그 폐허” 시험은 중단하고 해당 번호를 기록합니다.
5. **미리보기:** 위치·형태·윤곽·개수·큰 간격을 비교합니다. **실제 정착지 생성:** 정확한 지형 재료, 벽·바닥·지붕·동면관·전리품·동물·통행 가능 여부를 확인합니다. 고대 위협의 주황 테두리는 예약 공간이며 내부 미리보기가 아닙니다.
6. 실제 정착지를 만든 뒤 텍스트를 바꿔도 이미 생성된 맵을 실시간으로 개조하지 않습니다. 수정 결과의 완성맵을 비교하려면 정착 직전 별도 저장에서 다시 시작하거나 다른 테스트 타일을 사용합니다. 미리보기와 실제 맵은 기존 건물·예약 공간 때문에 배치 위치가 달라질 수 있습니다.
7. “거절 기대”는 **설명하고 기존 상태를 유지해야 통과**입니다. “배치 실패 기대”는 사전 안내 또는 실제 배치 실패가 정상이며, 설정 적용 여부와 건물 생성 성공을 구별합니다. 조건부 특징은 조건 충족/불충족에 따라 기대 결과가 달라집니다.

이미지 입력 테스트는 제외했습니다. Fable이나 별도 모델 호출을 요구하는 문장도 없습니다. 건물 간격은 최소 간격이며 등간격을 뜻하지 않습니다. 지형과의 거리는 가장 가까운 건물 칸 기준입니다. 자연 생성 밀도는 정확한 생성 개수가 아닙니다.

빠르게 시작하려면 **A01~A05 → 초기화 → F01~F04 → 초기화 → L01~L03** 순서를 권합니다. F그룹은 Odyssey가 필요합니다. 원하는 그룹만 골라 진행해도 됩니다.

## A. 정확한 원형 ↔ 자연스러운 원형

**준비:** 기본 타일. A01부터 A05까지 같은 타일에서 순서대로 입력.

### A01 · 생성

```text
중앙에 정확한 원형 호수를 하나 만들어줘. 지름은 맵 너비의 40% 정도로 하고, 가운데 섬은 만들지 마.
```

**눈으로 확인:** 중앙이 물로 채워진 원형. 가운데가 빈 도넛으로 나오지 않는지 확인.

결과: □ 미실행 □ 기대대로 □ 다름 □ 조건 부족 / 메모: __________

### A02 · 수정

```text

```

**눈으로 확인:** 대략적인 원형은 유지하면서 물가가 불규칙해짐. 호수가 늘어나거나 중심이 이동하면 기록.

결과: □ 미실행 □ 기대대로 □ 다름 □ 조건 부족 / 메모: __________

```text
그 호수의 윤곽을 살짝만 울퉁불퉁하게 해줘. 다른 건 그대로 둬.
```

**눈으로 확인:** A02보다 약한 굴곡. 위치·물 재료·대략적인 크기 유지.

결과: □ 미실행 □ 기대대로 □ 다름 □ 조건 부족 / 메모: __________

```text

```

**눈으로 확인:** A03보다 강한 굴곡. 가운데 구멍이나 별개의 호수가 생기지 않는지 확인.

결과: □ 미실행 □ 기대대로 □ 다름 □ 조건 부족 / 메모: __________

```text

```

**눈으로 확인:** 울퉁불퉁한 윤곽이 사라지고 A01과 같은 위치·규모의 원형으로 복귀.

- A04 직후 **되돌리기/Undo**를 한 번 눌러 A03의 약한 굴곡으로 돌아오는지 비교합니다. 확인 후 A04를 다시 입력하면 다음 단계로 이어갈 수 있습니다.
