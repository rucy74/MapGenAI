# Geological Landforms 풍경을 MapGen AI에 요청하기

확인: 2026-09-26. **아래는 MapGen AI DEV의 텍스트 요청 예시와 지원 범위 안내입니다. GL 원본과 같은 맵을 보장하는 프리셋 목록이나 전종 검증 결과가 아닙니다.** 짧은 묘사부터 시작하고, 마음에 드는 큰 구도가 나온 뒤 물·생활 공간·출입로를 다듬는 용도입니다.

## 먼저 구분할 것

1. **비슷한 풍경을 직접 설계하기:** MapGen AI의 산·물 도형, 통로, 자연지형 조합을 사용합니다. 이번 공통 곡선·관계 배치는 굽은 산줄기·평지·길쭉한 물 영역에 같은 기반을 쓰고, 직접 만든 기준 영역 안·안쪽 가장자리·옆에 다른 요소를 연결합니다. Geological Landforms를 설치할 필요는 없습니다. GL 원본의 수식·시드·특수 규칙을 재현하지는 않습니다.
2. **설치된 실제 지형 특징을 추가하기:** 활성 모드가 제공한 특징을 현재 타일의 조건 안에서 요청합니다. GL 1.6도 `TileMutatorDef`를 제공하므로 일반 특징 목록에 노출될 수 있습니다. 그러나 GL의 모든 특징을 MapGen AI에서 추가·수정했을 때 정상 생성되는지는 아직 전종 검증하지 않았습니다. [GL 1.6 특징 정의](https://github.com/m00nl1ght-dev/GeologicalLandforms/blob/master/1.6/Defs/TileMutators.xml)
3. **GL 원본을 그대로 플레이하기:** GL 자체의 지형 검색으로 원하는 종류의 월드 타일을 찾는 방법이 가장 직접적입니다. MapGen AI에 이름을 말하는 것과 GL의 원본 생성기를 그대로 선택하는 것은 같지 않습니다. [GL 공식 사용 안내](https://steamcommunity.com/sharedfiles/filedetails/?id=2773943594)

GL 현재 Workshop 설명은 43종이며, Odyssey가 켜져 있으면 겹치는 14종을 기본적으로 비활성화한다고 안내합니다. 강 관련 항목은 별도의 기본 우선순위와 설정이 있습니다. 따라서 다른 사람의 GL 사진에 나온 이름이 자신의 활성 특징 목록에 모두 있는 것은 아닙니다. [Odyssey 호환 안내](https://steamcommunity.com/sharedfiles/filedetails/?id=2773943594)

## 바로 시도하기 좋은 육상·호수 풍경

**아래 판정은 MapGen AI 자체 생성 범위에 대한 설명입니다. 모든 예문은 사용자 비교용이며 이번 빌드에서 전부 실측 성공한 문장이 아닙니다.** 한국어 이름은 이해를 돕는 풀이이고 GL의 공식 번역과 다를 수 있습니다.

작은 연못 등을 자동으로 붙일 때는 가장자리 전환을 포함한 전체 직사각형이 들어갈 공간을 검사합니다. 좁고 굽은 영역에서는 모양을 잘라 넣지 않고 배치 불가를 안내할 수 있습니다. 그런 경우 연못을 작게 하거나 기준 영역을 넓히는 요청으로 조절합니다. 국소 물 영역은 실제 세계 강의 흐름이나 수문 현상을 구현하는 기능이 아닙니다.

| GL에서 참고한 풍경 | MapGen AI에 보낼 문장 | 범위 |
|---|---|---|
| Valley — 골짜기 | `큰 산줄기 사이에 넓고 완만하게 굽은 골짜기를 만들어 줘. 마을 지을 땅은 넉넉하게.` | 육상 형태 근사. |
| Cirque — 한쪽 열린 산악 공간 | `산이 세 방향을 감싸고 남쪽으로 넓게 열린 정착지로 만들어 줘. 완벽한 원형은 싫어.` | 열린 분지·산줄기 조합으로 근사. |
| Cliff / Cliff Corner — 가장자리 산벽 | `북쪽과 서쪽에 산줄기가 있고 나머지는 넓게 트인 평야로 만들어 줘.` | 2D 산·평지 배치 근사. 높낮이가 있는 입체 절벽 시스템은 아님. |
| Lone Mountain — 독립된 산 | `넓은 평야 한쪽에 커다란 바위산 하나를 놓아 줘. 산 주변으로 돌아다닐 공간은 남겨 줘.` | 기존 산 도형·배치 기능으로 구성. |
| Canyon — 협곡 | `두 바위산 사이를 동서로 통과하는 굽은 협곡을 만들어 줘. 통로는 최소 12칸 폭으로.` | 산과 마른 통로를 조합. GL 협곡의 자원·채광 구성까지 복제하지 않음. |
| Rift — 좁고 긴 틈 | `큰 산 덩어리 가운데 길고 좁은 틈이 남북으로 이어지게 해 줘. 물길 말고 마른 통로로.` | 지상 산 틈 근사. 지하·지붕 효과 없음. |
| Gorge — 물길을 낀 협곡 | `기존 강 양옆에 바위산이 이어지는 협곡으로 만들어 줘. 강 한쪽에는 생활할 평지를 남겨 줘.` | 실제 강 타일에서 배치 근사. 강 없는 타일에 세계 강을 새로 만들지 않음. |
| Crater / Caldera — 분화구·칼데라 | `큰 분화구 같은 고리 산을 만들어 줘. 안쪽은 마른 평지로 남기고 산 윤곽은 자연스럽게.` | 고리 산의 외형 근사. 정확한 닫힌 고리는 요청대로 닫힐 수 있으므로 출입이 필요하면 출구도 요청. |
| Lake — 호수 | `한쪽에 자연스러운 큰 호수, 반대쪽에 넓게 연결된 정착 공간을 만들어 줘.` | 국소 물 도형. 세계지도 호수 타일을 만드는 기능은 아님. |
| Lake with Island — 호수 속 섬 | `불규칙한 호수 안에 마른 섬 하나가 있고, 호수 바깥에도 정착할 땅이 넓게 남게 해 줘.` | 물과 마른 영역의 외형 근사. 섬의 출입 동선은 별도 확인. |
| Dry Lake — 마른 호수 자리 | `평야 한쪽에 말라버린 호수 바닥처럼 불규칙한 모래 지대를 만들어 줘. 물은 넣지 마.` | 재료·외형 근사. GL의 생성 규칙 자체는 아님. |
| Badlands / Desert Plateau — 황무지·사막 고원 | `건조한 평야에 높이와 크기가 다른 바위 능선들이 있고, 사이사이 넓은 마른 땅이 이어지게 해 줘.` | 산·바닥 구도 근사. 실제 고도 층·침식 시뮬레이션 없음. |
| Oasis — 오아시스 | `사막에 작은 물가와 그 주변 생활 공간이 있는 오아시스 같은 풍경을 만들어 줘.` | 물·바닥 외형 근사. 실제 오아시스 특징을 원하면 '특징 추가'라고 구분하고 바이옴 조건을 따라야 함. |
| Swamp Hill — 습지 속 언덕 | `습지 타일에서 마른 정착 공간 옆에 작은 바위 언덕이 있고 주위 습지를 살린 풍경으로 만들어 줘.` | 배치 근사. 모든 습지 재료를 자동 배수하거나 바이옴 생태를 교체하지 않음. |

이 이름들은 [GL 공식 목록](https://github.com/m00nl1ght-dev/GeologicalLandforms#list-of-landforms)과 [현재 특징 정의](https://github.com/m00nl1ght-dev/GeologicalLandforms/blob/master/1.6/Defs/TileMutators.xml)를 참고했습니다. **예문의 구성과 MapGen AI 범위 판정은 이 프로젝트의 분석**입니다.

## 세계지도 조건이 먼저인 풍경

이 모드는 기존 세계 강·바다 연결을 보존합니다. 내륙을 바다로 바꾸거나 다른 타일에서 강을 새로 끌어오는 예문은 제공하지 않습니다. 강 방향 변경, 국소 연못 추가와 세계 연결 생성은 다릅니다.

| GL 풍경 묶음 | 시도할 조건과 문장 | 중요한 한계 |
|---|---|---|
| Coast / Coast Corner / Coast with Cliff | 실제 해안에서 `지금 해안을 살리고 육지 쪽에 산을 등진 정착지를 만들어 줘.` | 세계 해안은 있어야 함. 해안의 세부 외형과 GL 원본 일치는 미보장. |
| Cove / Secluded Cove | 실제 해안에서 `바다가 들어오는 작은 만을 바라보는 정착지 느낌으로, 육지 양쪽에 산이 있고 가운데는 트이게 해 줘.` | 산 배치로 만의 분위기를 근사할 수 있지만 기존 해안을 임의로 지워 완전히 새로 그리는 기능은 아님. |
| Cove with Island / Coastal Island | 실제 해안·해당 특징 지원 시 `해안 가까운 섬이 있는 지형 특징을 쓸 수 있어? 가능하면 먼저 추천으로 보여 줘.` | 일반 도형으로 보호된 바닷물을 확실히 육지로 바꾸는 기능을 보장하지 않음. |
| Fjord | 실제 해안에서 `이 타일에서 가능한 피오르드 특징을 추가해 줘.` | 활성 특징과 타일 조건이 맞아야 함. GL 제공인지 Odyssey 제공인지 구분. |
| Peninsula / Isthmus / Tombolo | 조건에 맞는 해안에서 `이 타일에서 반도나 좁은 육지 연결 지형이 가능한지 보고, 가능한 쪽을 추천해 줘.` | 외관만 비슷한 두 연못 사이의 땅과 실제 바다 지형을 혼동하지 않음. 원본 GL 방식은 검증 대상. |
| Island / Atoll / Archipelago / Skerry | 바다 지형을 지원하는 타일·활성 특징이 필요. `이 타일에서 가능한 섬 지형을 알려 줘. 없으면 내륙 호수로 대신 만들지는 마.` | MapGen AI 자체로 임의 타일의 완전한 섬·군도 생성 지원을 선언하지 않음. |
| River | 실제 강 타일에서 `기존 강을 살리고 양옆에 정착하기 좋은 풍경을 만들어 줘.` | 기존 강 사용. 물 도형을 흐르는 강이라고 부르지 않음. |
| River Confluence / River Source / River Delta / River Island | 실제 연결 조건에 맞는 타일에서 `이 강 타일에 가능한 합류점·발원지·삼각주·강 섬 특징 중에서 추천해 줘.` | 종류별 연결·해안 조건이 다름. 특정 특징이 없으면 단순 물 도형으로 성공 처리하지 않음. |

GL의 강 계열과 Gorge·Glacier는 1.7.0 변경 기록에서 추가가 확인됩니다. README의 이전 '36종'만 보고 현재 목록을 판단하지 않았습니다. [GL 변경 기록](https://github.com/m00nl1ght-dev/GeologicalLandforms/blob/master/Changelog.md)

## 자체 생성으로 아직 같게 만들 수 없는 부분

| GL 풍경 | MapGen AI 자체 생성의 한계 | 근사할 때 구분 |
|---|---|---|
| Cave Entrance / Surface Cave / Sinkhole / Secluded Valley | GL식 대규모 동굴·두꺼운 지붕·지하 연결·사건 처리 전체를 재현하는 기능은 없음. | `지상에서 산이 감싼 공간과 출입구` 정도로 한정. 보통의 동굴 특징 추가와 GL 동굴 전체 재현은 다름. |
| Ice Oasis | 얼음 지형 안의 오아시스를 만드는 GL 원본의 생성 규칙을 자체 도형만으로 재현하지 않음. | 눈·얼음 재료로 모양만 만드는 것과 구별. |
| Glacier | 빙하 원본의 지형·재료·세계 조건을 자체 생성으로 복제하지 않음. | 얼음 영역을 배치했다고 실제 빙하 지형 특징을 구현한 것은 아님. |

GL 자체는 큰 동굴 지붕과 출입을 위해 별도 처리를 갖고 있습니다. 따라서 위 항목을 '산을 많이 놓으면 동일하게 구현됨'으로 설명하지 않습니다. [GL 동굴·붕괴 설명](https://steamcommunity.com/sharedfiles/filedetails/?id=2773943594)

## 이름을 몰라도 요청하는 요령

`골짜기` 같은 이름만 알아도 시작할 수 있지만, 가장 중요한 한 가지를 덧붙이면 해석을 비교하기 쉽습니다.

- `살기 편하게` — 넓은 마른 생활 공간과 출입을 우선.
- `자연스럽게` — 굴곡과 요소 간 배치를 맡김. 정확한 기하형과 구별.
- `기존 강을 활용해서` — 이미 있는 물을 중심으로 구성.
- `산은 한쪽만` / `물이 너무 크지는 않게` — 싫어하는 결과를 구체화.
- `정확한 원형으로` — 자연스러운 변형보다 명시한 도형을 우선.

예: `호숫가 마을이 어울리는 풍경. 산은 한쪽만 있고 물이 생활 공간을 가르지는 않게.`

후속으로는 `호수만 작게`, `왼쪽 산만 낮춰`, `물가는 좋은데 마른 공간을 넓혀`처럼 대상과 바꿀 점을 말하면 됩니다. 다른 요소를 보존하라는 문구가 매번 필수인 것은 아닙니다. 이런 짧은 편집을 제대로 처리하는지도 [다양한 테스트 목록](text-landscape-test-ko.md)에서 확인합니다.
