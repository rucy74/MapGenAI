## 사용할 자료

이번에 사용할 폴더는 **upload-v6/**다. 이전 `upload/`, `cards/out/`은 보관본이다.

| 위치 | 처리 | 준비 파일 |
|---|---|---|
| 대표 표지 | 사용자가 채택한 v5로 교체 | [Preview.png](upload-v6/2-cover/Preview.png) |
| 본문 카드 | 새 네 장을 호스팅하고 새 직접 이미지 URL 사용 | [카드 폴더](upload-v6/1-imgur) |
| 설명 | 기존 설명을 새 한·영 글로 교체 | [영어](description-en.txt), [한국어](description-ko.txt) |
| 상단 갤러리 | 기존 좋은 지형 예시는 유지하고 아래 최신 기능 화면 추가 | [갤러리 폴더](upload-v6/3-steam-gallery) |
| 영상 | 기존 영상 유지 | 새 시안은 이번 등록 묶음에서 제외 |

**설명 파일은 아직 URL 템플릿이다.** `CARD_01_URL`~`CARD_04_URL`을 새 이미지 URL로 채우기 전에는 그대로 붙여 넣지 않는다. 이전 Imgur 네 주소는 이전 카드이므로 새 소개글에 다시 넣지 않는다.

## 갤러리 순서 제안

1. 기존 대각선 협곡 + 중앙 호수 예시 유지.
2. 기존 피오르 예시 유지.
3. 기존 별 모양 언덕 + 초승달 호수 예시 유지.
4. `gallery-01-recommendations.png`: 최신 추천·재추천·선택 안 함 UI.
5. `gallery-02-preferences.png`: 취향 문답 화면.
6. `gallery-03-editing.png`: 후보를 고르기 전에 대화로 수정하는 화면.
7. `gallery-04-road-bridge.png`: 실제 생성 맵의 흙길과 나무 다리.

기존 산악 요새/비옥한 계곡 등 내용이 다른 좋은 예시는 추가로 유지해도 된다. 오래된 대화 UI·설정 화면·반복되는 도넛 예시를 교체 대상으로 삼는다. 공개 갤러리의 각 이미지 번호와 원본을 모두 대조해 삭제 목록을 확정한 것은 아니므로 번호만 보고 삭제하지 않는다. **갤러리 전체 삭제는 하지 않는다.**

## 실제 반영 순서

1. `upload-v6/1-imgur` 새 PNG 네 장을 호스팅한다. 앨범 주소가 아니라 이미지 파일의 직접 URL을 얻는다.
2. `description-en.txt`, `description-ko.txt`의 네 자리표시자를 같은 순서의 새 URL로 교체한다. BBCode 검사 후 로컬 검토 화면과 대조한다.
3. 최신 모드 파일과 새 표지를 기존 Workshop ID로 업데이트한다. 게임 업로더는 웹 설명을 갱신하지 않으므로 다음 단계도 필요하다.
4. 같은 항목의 웹 설명 편집에서 EN/KO 글을 각각 교체한다.
5. 갤러리에 새 기능 화면 네 장을 추가하고, 유지할 예시와 중복되는 옛 UI 사진을 선별한다.
6. 공개 페이지에서 표지·두 언어 설명·이미지 표시를 확인한다.
