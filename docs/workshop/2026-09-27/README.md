# MapGen AI 창작마당 갱신 자료 (2026-09-27)

창작마당 [MapGen AI](https://steamcommunity.com/sharedfiles/filedetails/?id=3685385453) 페이지의 소개글·사진·영상을 새 빌드에 맞춰 바꾸기 위한 자료다. 구성은 Living Screens 게시 때 쓴 방식을 따른다. 글과 이미지를 섞은 본문, 실게임 캡처로만 만든 이미지 카드, 목록 크기에서 읽히는 표지를 쓴다.

## 먼저 알아 둘 점

- **지금 창작마당 파일은 8월 22일 빌드다.** 9월 기능이 없다. 새 소개글은 최신 DEV를 일반판으로 올리는 날 함께 바꿔야 한다. 먼저 바꾸면 구독자가 없는 기능을 설명하게 된다.
- **게임 안 업로더는 설명을 바꾸지 않는다.** 제목·표지·파일은 업로드 때 갱신되지만 설명은 처음 만들 때만 들어간다(Living Screens 작업 때 게임 코드로 확인). 설명은 스팀 웹 페이지에서 직접 붙여 넣는다.
- **이미지는 외부 주소가 필요하다.** 스팀 설명에는 이미지를 직접 올릴 수 없다. 카드 PNG를 Imgur 등에 올리고 그 직접 주소를 넣는다.

## 올리는 순서

1. 카드 PNG를 Imgur에 올린다. 직접 이미지 주소를 알려 주면 설명 두 파일의 `CARD_0N_URL` 자리에 넣는다.
2. 고른 표지를 `dist/About/Preview.png`에 넣고 일반판 승격과 업로드를 한다. 승격 스크립트는 이 파일을 그대로 가져간다.
3. 스팀 페이지의 제목 및 설명 편집에서 영어 설명에 `description-en.txt`, 한국어 설명에 `description-ko.txt` 전체를 붙여 넣는다.
4. 이미지·영상 추가 편집에서 옛 대화창 스크린샷을 내리고 새 캡처를 올린다.
5. 새 영상을 YouTube에 올린 뒤 같은 화면에서 링크를 넣고 옛 영상을 내린다.

## 검증 범위

- 설명 문장은 현재 코드와 사용자 설명서에 대조했다: 공급자 11종, 버튼 이름, 추천 최대 3개, 취향 문답의 AI 무호출, 키 저장 위치, 일부 새 안내의 영어·한국어 한정.
- 스팀 서식은 `check_bbcode.py`로 검사했다. 잘못된 표본을 잡는지 먼저 시험한다.
- 스팀에 붙여 넣은 뒤의 실제 모양과 Imgur 이미지 표시는 확인하지 않았다.

## 이번 캡처 결과 (2026-09-27 10:00, showcase-01)

- **조건**: 격리 런타임, 영어 UI, 1920×1080, UI 배율 1.5, 출시 후보 DLL 4908863336…, 실제 Gemini 호출 11회.
- **기본 6종**: 도넛 산·섬 추가·섬 이동·직선 강·온천·해안 방향 PASS. 강 위치는 FAIL. 서→동으로 흐르는 강에 "서쪽으로"라고 요청한 시험 설계 실수였지만, 제품이 "Move the river toward the west"라고 답해 결과와 설명이 어긋났다.
- **제품 문제 3건**: ① 통로 막힘·도로 실패 안내가 한국어와 영어를 붙인 고정 문장이라 영어 화면에 한국어가 나온다. ② 온천만 추가해도 강이 북쪽으로 옮겨진다. ③ 도로 요청이 산 안쪽 경유점을 골라 도로가 놓이지 않았다.
- **이미지에서 한 조치**: 한국어가 보이는 부분은 잘라 냈고, 문제 장면(강 옮기기·온천·도로)은 카드와 시안 영상에서 뺐다. 설명의 예시도 오늘 확인했거나 이전 실측이 있는 요청으로 바꿨다.
