[h1]원하는 맵을 말하면, MapGen AI가 만들어 줍니다.[/h1]
"가운데 호수를 품은 고리 모양 산", "호수 한가운데에 작은 섬을 넣어 줘"처럼 평소 말로 입력하세요. MapGen AI가 맵 설정으로 바꾸고, Map Preview가 결과를 바로 보여 줍니다. 마음에 들 때까지 대화로 다듬은 뒤 그 자리에서 시작하면 됩니다.

[b]RimWorld 1.6용입니다.[/b] [url=https://steamcommunity.com/sharedfiles/filedetails/?id=2009463077]Harmony[/url]와 [url=https://steamcommunity.com/sharedfiles/filedetails/?id=2800857642]Map Preview[/url]가 필요합니다.
[b]AI는 직접 고릅니다:[/b] Google Gemini, OpenAI, OpenRouter, DeepSeek, Grok, GLM, Alibaba, Ollama·LM Studio 같은 로컬 서버, 직접 지정한 주소를 쓸 수 있습니다.

[h2]이번 업데이트에서 달라진 점[/h2]
[list]
[*][b]앞서 만든 지형이 유지됩니다.[/b] 호수를 만든 뒤 옮기거나, 크기만 바꾸거나, 물가 모양만 바꿀 수 있습니다. 앞선 변경은 그대로 남고, 되돌리기는 요청 하나씩 뒤로 돌아갑니다.
[*][b]그림으로 보는 추천.[/b] 추천을 요청하면 Map Preview로 그린 후보를 최대 3개까지 보여 줍니다. 고르기 전에 "2번을 더 자연스럽게"처럼 다듬을 수 있고, 직접 선택하기 전까지 맵은 바뀌지 않습니다.
[*][b]취향 문답.[/b] 무엇을 원하는지 막막하면 객관식 질문 몇 개에 먼저 답해 보세요. 질문은 PC 안에서 진행되고 AI를 호출하지 않습니다.
[*][b]정확한 도형과 자연스러운 모양.[/b] 완벽한 원형도, 물가가 울퉁불퉁한 자연스러운 호수도 요청할 수 있습니다.
[*][b]영역의 일부만 채우기.[/b] "고리 안쪽의 70%만 비옥한 토양으로" 같은 요청이 됩니다. 용암 채우기는 Odyssey가 있을 때 쓸 수 있습니다.
[*][b]폐허와 고대 위협 배치.[/b] 섬 안, 산기슭처럼 영역·방향·지형을 기준으로 놓을 수 있습니다. 고대 위협은 게임 기본 생성기로 만듭니다.
[*][b]다리가 놓이는 지역 도로.[/b] 강이나 얕은 물을 건너는 구간에는 나무 다리가 자동으로 놓입니다.
[*][b]자연스러운 물.[/b] 새로 추가하는 자연 호수는 게임 기본 호수처럼 얕은 가장자리와 바이옴에 맞는 호숫가 바닥을 갖습니다.
[/list]

[h2]시작하는 방법[/h2]
[olist]
[*]MapGen AI, Harmony, Map Preview를 구독합니다.
[*][b]모드 설정 > MapGen AI[/b]에서 공급자를 고르고 API 키와 모델을 입력합니다.
[*]월드맵에서 타일을 고르고 Map Preview 옆의 [b]✦ AI 맵 생성[/b] 버튼을 누릅니다.
[*]원하는 맵을 입력하거나 [b]바로 추천받기[/b] 또는 [b]취향에 맞춰 추천받기[/b]를 누릅니다.
[*]미리보기가 마음에 들면 [b]이 설정으로 맵 생성[/b]을 누릅니다. 그 타일에서 시작하거나 정착할 때 이 설정이 적용됩니다.
[/olist]

[h2]요청 예시[/h2]
[list]
[*]"가운데에 호수를 품은 고리 모양 산을 만들고, 남쪽으로 출구 하나를 내 줘."
[*]"호수 한가운데에 작은 섬을 넣어 줘."
[*]"섬을 호수 북쪽으로 옮겨 줘." / "강을 곧게 펴 줘."
[*]"고리 안쪽의 70%만 비옥한 토양으로 채워 줘."
[*]"섬 안에 작은 폐허 두 개를 놓아 줘."
[*]"맵 서쪽 끝에서 동쪽 끝까지 흙길을 내 줘."
[*]"온천을 추가해 줘." (Odyssey)
[*]"해안을 북쪽으로 바꿔 줘."
[*]"그냥 추천해 줘." / "2번을 더 자연스럽게 해 줘."
[/list]

[h2]알아 두면 좋은 점[/h2]
[list]
[*][b]새로 시작할 맵을 만드는 모드입니다.[/b] 이미 플레이 중인 정착지 맵을 고치지는 않습니다.
[*][b]월드의 강과 해안 연결은 유지됩니다.[/b] 강을 곧게 펴거나 해안 방향을 바꿀 수는 있지만, 강·해안을 없애거나 내륙에 해안을 만들 수는 없습니다.
[*][b]Map Preview는 지형과 배치를 보여 줍니다.[/b] 식물, 건물 내부, 전리품은 실제 맵을 생성할 때 나타납니다.
[*][b]결과는 모델에 따라 달라집니다.[/b] 미리보기로 확인하고, 잘못되면 되돌리기나 초기화를 쓰세요.
[*][b]DLC와 랜드마크 모드:[/b] 해당 DLC나 모드가 켜져 있고 타일 조건이 맞으면 온천, 피오르드, 오아시스 같은 지형 특징을 추가할 수 있습니다.
[*][b]비용과 개인정보:[/b] 메시지 하나가 내가 고른 공급자에 내 키로 보내는 요청 하나입니다. 긴 대화를 요약하거나 형식이 깨진 답을 다시 받을 때처럼 요청이 하나 더 드는 경우가 있습니다. API 키는 내 PC의 RimWorld 모드 설정에 저장됩니다.
[*][b]언어:[/b] 메뉴는 영어, 한국어, 일본어, 중국어(간체)를 지원합니다. 일본어와 중국어에서는 새로 추가된 일부 안내가 영어로 나옵니다.
[*][b]이미지 입력은 이번 버전에서 잠시 꺼 두었습니다.[/b]
[*][b]프리셋:[/b] 저장·불러오기로 자주 쓰는 맵 설정을 다시 쓸 수 있습니다.
[/list]
