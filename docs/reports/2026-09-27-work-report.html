01 / 전체 변화

핵심은 “도형 추가”에서 “풍경 구성”으로 넓힌 것

공통 도구

굽은 산·평지·물을 같은 방식으로

분지 전용 예외를 늘리는 대신 공통 곡선과 안쪽·가장자리·옆이라는 배치 관계를 추가했다. 기준 지형을 옮기면 연결된 요소도 따라가도록 저장한다.

첫 요청

원래 땅을 살리는 풍경 구성

빈 공간 전체를 Soil로 덮지 않고 바이옴 바닥을 남기도록 수정했다. 자연 풍경 요청에는 어울리는 작은 물을 함께 고려하되, 물을 원치 않는 지시는 우선한다.

추천

위치·군집·여백의 변주

새 추천에서 방위와 중심, 굽은 지형·분기·크기가 다른 군집을 바꾸도록 했다. 기존 맵 시드나 이미 만든 지형을 후속 요청마다 다시 뽑는 방식은 아니다.

취향 문답

앞선 답변에 맞게 선택지 조정

물과 산의 선호, 이미 있는 지형, 기존 구도를 유지할지에 맞춰 질문을 조정한다. 작은 연못을 고른 뒤 큰 만을 권하거나, 없앨 물을 전제로 질문하는 모순을 줄였다.

물 표현

기본 게임의 물·물가 생성 규칙 적용

새 자연형 담수의 윤곽과 수심을 연결했다. 가장자리에 얕은 물을 두고 바이옴에 맞는 물가 재료를 고른다. 사막까지 무조건 진흙으로 두르지 않는다.

기존 기능 보존

정확한 도형·저장·온천 등을 대조

기존 저장의 물 윤곽·수심을 새 방식으로 자동 교체하지 않는다. 도로, 지정 재료, 비율 채움 영역, 물 안의 섬을 별도 조건으로 검사했다. 이미 자연 효과가 켜진 저장의 주변 물가는 달라질 수 있다.

아직 “알아서 항상 예쁜 맵을 만든다”까지 완성된 것은 아니다. 지형 표현 기능과 물가 처리는 개선했지만, 추천 모델의 전체 구도 선택과 기존 강·호수를 알아보고 활용하는 능력은 다음 과제다.

03 / 공통 지형 도구

분지 하나에만 맞춘 개선에서 벗어나기

산줄기, 골짜기, 평지, 긴 물을 여러 점을 잇는 곡선으로 표현할 수 있게 했다. 자연스러운 윤곽이면 폭이 조금씩 변하고 끝이 가늘어지며, 정확한 모양을 원할 때의 기존 동작은 유지한다.

형태
어떤 모양인가굽은 산줄기, 갈라지는 능선, 긴 물, 열린 평지 등을 공통 도구로 표현한다.
관계
무엇의 어디인가기준 영역의 안쪽·안쪽 가장자리·바깥 옆이라는 관계를 저장한다.
후속 편집
무엇을 유지할 것인가기준을 이동하면 관계 요소도 다시 배치한다. 위치만 바꾸는 요청이 모양 교체로 번지는 응답을 검사한다.

공간이 부족하면 원래 산을 지우거나 연못을 멋대로 줄여서 끼워 넣지 않는다. 보호해야 할 지형 때문에 배치가 거절될 수 있으며, 이 제한을 없애는 대신 이유를 남긴다.

그림 읽는 법: 이 세 장은 기능을 확인하려고 설정한 입력의 실제 생성 결과다. 모델이 자연어 요청을 매번 이렇게 해석한다는 증거는 아니다. 실제 추천 결과는 다음 절에 따로 있다.

첫 요청의 바닥과 부가 지형도 조정했다

평지를 만들 때 높이만 조정하고 재료를 고정하지 않으면 원래 바이옴의 지면을 남길 수 있다. 모델에도 이를 우선하도록 안내했다. 자연 풍경에서는 작은 물을 함께 고려하되, “건조하게”, “물 없이” 같은 선호를 앞세운다.

MG36의 실제 응답 예다. 당시 원형 분지의 큰 실루엣은 여전히 인공적으로 보였고, 첫 재추천에서 비옥토를 35% 넣은 실패도 기록에 남겼다.

표현할 수 있는 요청의 방향

“굽은 골짜기 사이에 정착할 평지를 넓게 두고, 한쪽 가장자리에 작은 연못을 넣어 줘.”

“작은 점 같은 언덕을 잔뜩 흩뿌리지 말고, 크기가 다른 몇 개의 바위 능선을 자연스럽게 묶어 줘.”

“이 평지를 북쪽으로 옮겨 줘. 모양은 그대로 두고 옆 연못도 따라가게 해 줘.”

04 / 추천과 취향 문답

무엇을 추천하고, 어떻게 취향을 묻는가

기본 추천은 선택한 타일의 조건과 사용자 선호를 우선하고, 새 후보를 만들 때 방위·중심·군집·분기·연결된 생활 공간을 달리하도록 했다. 현재 맵이나 후속 수정까지 매번 무작위로 바꾸는 방식은 아니다.

실제 결과에서 확인된 한계: 새 추천 9개 중 곡선을 사용한 후보는 7개였지만, 배치 관계 기능을 직접 사용한 후보는 0개였다. 방향과 군집은 달라졌어도 “한쪽 산 + 빈 공간” 구도가 계속 나오는 경향은 남았다.

기존 질문 분기에 앞선 답변 반영을 보완했다

질문 자체는 미리 준비한 로컬 질문과 선택지다. API 모델이 질문을 매번 새로 쓰는 방식은 아니다. 기본 구성은 6개이며, 특별한 풍경이나 기존 구도 유지 여부에 따라 최대 8개까지 다루고 중복 질문은 생략한다.

  • 이전 답변 반영: 산의 양, 물의 양, 연결된 생활 공간, 특별한 풍경 선호를 뒤 질문에 반영한다.
  • 선택지의 모순 완화: 작은 연못을 원하면 큰 만을 예로 들지 않는다. 가능한 방향이 하나뿐이면 추가 질문을 건너뛴다.
  • 물의 출처 구분: 타일 자체의 강·해안과 대화에서 추가한 연못을 나눈다. 현재 구도를 교체하면 사라질 물을 뒤 질문의 전제로 삼지 않는다.
  • 되돌아가서 답변 변경: 앞 답을 바꾸면 그 답에 의존한 이후 선택도 정리한다.
  • 비용: 문답 분기는 로컬에서 처리하고, 마지막 확인 뒤 추천 후보를 만들 때 모델을 호출한다.

이번에는 문답 분기·뒤로가기·취소를 코드로 검사했다. 최신 문답 창의 실제 클릭과 한국어 줄바꿈 화면까지 촬영한 것은 아니다.

05 / 물과 물가

기본 RimWorld 생성 코드를 보고 바꾼 부분

설치된 게임의 고도·비옥도, 바위, 지면 패치, Lake/Oasis, 작은 섬 정리, 식물 생성 흐름을 직접 확인했다. 이전에도 기본 생성 위에서 작동했지만, 직접 추가한 물의 윤곽과 주변 처리는 자체 방식에 많이 의존했다.

1 / 윤곽
자연스러운 변형기본 게임의 좌표 변형 함수를 사용한다. 작은 연못이나 가느다란 물에 맞게 변형 크기를 조정한다.
2 / 수심
물 폭에 맞는 가장자리완성된 물 타일에서 육지까지 거리를 재어 얕은 물과 깊은 내부를 구분한다. 좁은 물이 전부 얕아지는 문제도 보정했다.
3 / 물가
바이옴에 맞는 재료기본 게임의 담수·호숫가 재료 선택을 사용한다. 물가가 항상 진흙이어야 하는 것은 아니며 모래가 맞는 곳도 있다.

온대림 · 같은 조건의 전후

사막 · 같은 조건의 전후

이전 단계에서는 물 바깥 육지의 효과를 최대 6칸으로 제한하고, 적합한 기후·지면에서만 진흙이 생기게 했다. 떨어져 있는 다른 연못의 영향도 차단했다. 최신 단계에서는 새 자연형 담수 자체의 윤곽·수심·기본 호숫가 재료를 함께 다뤘다.

참고한 기본 게임의 실제 결과

기본 Lake/Oasis는 위치와 크기가 다른 참고 결과다. 위 전후 비교의 정답 이미지로 쓰거나, 같은 설정으로 만든 결과처럼 비교하지 않았다.

기본 생성기를 통째로 다시 실행하지 않은 이유

기본 Lake 생성기는 맵 전체의 고도를 정리하고 호수 중심을 바꾸며 타일·DLC 조건도 전제한다. 작은 연못 하나를 추가할 때 그대로 실행하면 범위가 너무 커진다. 따라서 기본 생성 순서는 유지하고, 지정한 영역에서 관련 규칙과 함수를 사용했다.

지면 생성이 끝난 뒤 원래 지면 함수를 다시 부르면 원래 땅 복원 대신 새로운 잡음과 난수 순서가 생길 수 있어 피했다. 식물 종류와 적합성 판단도 기본 게임 경로를 유지했다.

참조·사용한 주요 요소: MapNoiseUtility.AddDisplacementNoise, DeepFreshWaterTerrainAt, ShallowFreshWaterTerrainAt, LakeshoreTerrainAt, ShouldGenerateBeachSand.

06 / 보존과 검증

기존에 되던 것을 해치지 않도록 확인한 것

  • 기존 저장: 새 물 표현 설정이 없는 저장은 이전 물의 윤곽·수심을 유지한다. 이동하거나 작게 수정했다고 자동으로 새 방식으로 교체하지 않는다. 다만 이미 details:natural이 켜진 저장의 주변 물가 표현은 MG38/39 개선으로 달라질 수 있다.
  • 정확한 모양과 특수 물: 정확한 도형, 저장된 이전 자연형, 온천은 전후 미리보기와 완성 맵 지형이 동일한지 대조했다. 용암·염수 등도 일반 담수 처리의 대상에서 제외한다.
  • 효과 끄기: 새 자연형 담수에서 표면 효과를 꺼도 물의 윤곽과 수심은 유지한다. 검사 사례의 물 3,483칸은 같고 물가 429칸만 달랐다.

07 / 남은 문제

어디까지 왔고, 무엇이 아직 부족한가

기존 강·호수를 알아보고 활용하는 편집
현재 타일의 특징 이름과 실제 맵의 물 윤곽은 다르다. 모델이 기존 강과 호수의 위치·형태를 충분히 보고 그 주변만 바꾸는 수단은 아직 부족하다. “강가 마을”에 큰 물 도형을 새로 놓는 문제를 모두 해결한 상태는 아니다.

공통 도구와 방어 검사가 있어도 모델이 이를 항상 알맞게 선택하지는 않는다. 이동 요청에서 모양까지 바꾼 실제 응답은 회귀로 추가했지만, 수정된 방어 이후 모델의 재응답까지 새로 호출해 확인하지는 않았다.
Geological Landforms와의 관계
골짜기·능선·호숫가 같은 비슷한 풍경을 묘사할 공통 도구와 안내는 마련했다. Geological Landforms의 생성기를 직접 연결하거나 모든 지형을 동일하게 재현하는 수준은 아니다. 동굴·절벽·세계 수계 조건까지 일반화한 것도 아니다.
전체 모드·식물·성능
모든 바이옴과 외부 모드 조합, 최종 식물 화면, 장시간 플레이 성능은 미검증이다. 이전 단계의 드문 native 충돌과 최종 식물 엄격 검사 2개 실패도 이번에 해결했다고 처리하지 않았다.
