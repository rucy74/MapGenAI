# 물가와 취향 문답 — 직접 확인할 7가지

최신 **MapGen AI [DEV]**에서 확인한다. 일반판은 이번 변경 대상이 아니다. 설치 후 게임을 다시 실행하고, 테스트를 시작하기 전 상태를 저장해 두면 비교하기 쉽다. 각 사례는 별도 타일이나 초기화한 상태에서 시작하되, 아래에서 같은 맵을 쓰라고 한 경우에는 이어서 진행한다.

여기서 ‘직접 그린 물’은 `연못 만들어 줘`처럼 채팅으로 추가한 물을 가리킨다.

이 문서는 앞으로 사용자가 확인할 목록이다. 여기 적힌 문장으로 실제 추천 API가 올바르게 답했다는 검증 기록은 아니다. 문답은 **준비된 선택지를 앞선 답과 현재 설정에 따라 조정하는 로컬 문답**이며, 질문을 매번 API 모델이 만드는 방식이 아니다. 마지막에 추천을 확정하면 API를 요청한다.

이번에는 물가의 바닥 재질과 문답의 일관성을 본다. **원형 물 자체의 윤곽을 더 예쁘게 만들거나, 모델이 기존 강·호수의 실제 모양을 정확히 읽는 기능은 이번 범위가 아니다.**

## 1. 온대림의 작은 연못: 물가가 바닥과 이어지는가

- **준비:** 따뜻하고 비가 충분한 온대림의 흙 바닥. 기존 도로나 비옥한 토양을 피한 작은 빈터가 좋다.
- **입력:** `빈터 한쪽에 작은 자연스러운 연못 하나 만들어 줘. 주변 물가도 자연스럽게 해 줘. 나머지 산과 땅은 유지해.`
- **확인:** 물 바로 옆 일부에 진흙 등 주변에 맞는 바닥이 생기고, 바깥으로 갈수록 기존 땅으로 이어지는지 본다. 물 전체를 같은 폭의 진흙 띠가 둘러쌀 필요는 없다. 바위 가까이의 자갈도 허용되는 결과다.
- **문제 기록:** 넓은 모래·자갈 띠로 빈터가 줄어들거나, 멀리 떨어진 바닥까지 바뀌거나, 기존 길·비옥한 토양이 덮이면 전후 그림을 남긴다. 특정 타일에서 진흙이 없다는 사실만으로 실패로 판정하지 않는다. 실제 바이옴·기후·기존 바닥 조건에 따라 다르다.

## 2. 사막의 작은 연못: 습한 초원처럼 바뀌지 않는가

- **준비:** 사막이나 고열사막의 모래 빈터. 1번과 같은 크기 정도의 연못을 요청한다.
- **입력:** `작은 자연스러운 연못 하나 만들어 줘. 주변 물가는 이 사막에 어울리게 하고, 나머지 사막은 유지해.`
- **확인:** 모래 바닥이 자연스럽게 이어지고, 물가 자동 효과만으로 진흙이나 흙·비옥한 토양이 넓게 추가되지 않는지 본다. 바위 주변 또는 바이옴에 맞는 자갈은 가능하므로 ‘사막에는 자갈이 하나도 없어야 한다’는 기준은 아니다.
- **문제 기록:** 요청하지 않은 거대한 초원이나 비옥한 토양 영역이 생겼다면, 모델이 별도 영역을 추가했다고 답했는지 함께 남긴다. 별도 지형 추가와 물가 자동 효과를 구분하는 데 필요하다.

## 3. 서로 떨어진 물: 옆의 강 때문에 엉뚱한 물가가 생기지 않는가

- **준비:** 강이나 다른 물이 있고, 그 옆에 마른 땅이 몇 칸 남는 타일. 적당한 타일을 찾기 어렵다면 이 항목은 건너뛰어도 된다.
- **입력:** `기존 강과 연결하지 말고, 강 옆의 마른 땅에 작은 연못 하나 만들어 줘. 사이에는 마른 땅을 남기고, 새 연못 물가만 자연스럽게 해 줘. 기존 강은 유지해.`
- **확인:** 먼저 물이 실제로 서로 떨어져 있는지 본다. 떨어져 있다면 새 연못 주변 효과가 기존 강 전체를 따라 퍼지거나, 사이의 빈터를 넓게 덮지 않아야 한다. 물을 연결해 버린 결과는 이 사례의 조건을 충족하지 못한 것이므로 별도로 기록한다.
- **문제 기록:** 새 연못 쪽과 기존 강 쪽을 함께 찍는다. 가까운 다른 물이 재질 계산에 전혀 영향을 주지 않는다는 수치 검증을 스크린샷만으로 증명할 수는 없다. 이 수동 확인에서는 눈에 띄는 경계 변화와 과도한 확산을 찾는다.

## 4. 자동 물가 효과 끄기: 모양과 명시한 바닥은 유지되는가

- **준비:** 1번의 연못이 있는 같은 맵. 먼저 그림을 남기고 설정을 저장한다.
- **입력:** `자동 바닥·식생 조화 효과만 꺼 줘. 연못의 모양, 위치, 크기와 다른 지형은 유지해.`
- **확인:** 자동 효과가 꺼졌다는 응답을 확인하고 다시 생성한다. 연못 윤곽과 위치는 같아야 하며, 물가 자동 효과만 빠져야 한다. 직접 지정한 도로나 바닥까지 삭제하면 안 된다. 꺼진 상태를 저장하고 다시 불러와도 자동으로 켜지지 않아야 한다.
- **문제 기록:** ‘그런 기능이 없다’는 응답, 다른 지형 변경, 불러온 뒤 효과 재활성화를 기록한다. Map Preview에는 식물이 보이지 않으므로 식생까지 확인하려면 실제 맵을 생성해야 한다.

## 5. 직접 그린 연못만 있을 때: 교체 문답이 없는 물가를 전제하지 않는가

- **준비:** 세계 강·해안·호수 특징이 없는 타일에 작은 연못 하나를 직접 만든 상태.
- **문답 순서:** `다른 구도를 새로 비교하기` → `보기 좋은 풍경` → `탁 트인 생활 공간` → `타일의 물만 유지` → `넓게 이어진 한 공간` → `독특한 풍경 위주`.
- **확인:** 물 선택 설명에 직접 그린 연못을 이어 쓰지 않고 새 물도 추가하지 않는다는 의미가 있어야 한다. 생활 공간 질문에서 기존 물가를 따라가라는 선택지가 나오면 안 되고, 이후 물가의 특별함을 고르게 해서도 안 된다. 산 설명은 타일의 원래 산과 직접 그린 산을 구분해야 한다.
- **추가 확인:** `이전`으로 돌아가 `지금 구도를 다듬기`로 바꾼다. 이전의 뒤쪽 답변이 지워지고, 다시 산·물 선호를 고르면 이번에는 보존할 연못을 이용하는 물가 선택지가 가능해야 한다. 마지막에 취소하면 현재 맵은 바뀌지 않아야 한다.

## 6. 타일의 강과 직접 그린 연못이 함께 있을 때: 보존 대상을 구분하는가

- **준비:** 세계 강이 있는 타일에 별도의 작은 연못을 직접 만든 상태. 바다나 호수 특징이 있는 타일로도 대체할 수 있다.
- **문답 순서:** `다른 구도를 새로 비교하기` → 원하는 우선순위 → `탁 트인 생활 공간` → `타일의 물만 유지`.
- **확인:** 타일의 강·해안·호수 특징은 유지하고, 직접 그린 물은 이어 쓰지 않는다고 설명해야 한다. 5번과 달리 이번에는 타일의 물가를 따라 생활 공간을 놓는 선택지가 가능하다. 이전 답을 바꾸지 않고 뒤로 갔다 돌아왔을 때에는 선택이 유지되어야 한다.
- **문제 기록:** 문답 설명과 후보 그림을 구분해 남긴다. 추천을 요청한 뒤 모델이 그려 넣은 연못을 그대로 복제하거나 세계 강을 지운다면 모델의 최종 선호 준수 문제로 기록한다. 문답에 올바른 설명이 있다는 것만으로 후보도 올바르다고 판정하지 않는다.

## 7. 풍경·방어 우선이어도 ‘새 산·물 없음’을 지키는가

- **준비:** 강·해안·호수 특징이 없는 타일에서 설정을 초기화한 상태.
- **문답 순서:** `보기 좋은 풍경` → `탁 트인 생활 공간` → `지금 있는 물만` → `넓게 이어진 한 공간` → `독특한 풍경 위주` → `모양과 배치에 집중해 줘`.
- **확인:** 새 산이나 물가를 고르게 하는 후속 질문이 없어야 한다. 마지막 취향 요약에는 새 산·물·특징을 추가하지 않는 선호가 함께 남아야 한다. 시간이 있으면 첫 답만 `방어하기 편한 배치`로 바꿔 한 번 더 확인한다.
- **후보 확인:** 추천까지 요청한다면 예쁘게 만들거나 방어하기 좋게 만든다는 이유로 새 호수·산벽·온천을 추가하지 않는지 본다. 이는 실제 API 모델의 순응 확인이며 아직 검증 완료로 보장하지 않는다. 모든 답을 마치지 않고 `지금까지 답으로 마무리`를 써도 답하지 않은 항목을 골랐다고 요약해서는 안 된다.

## 피드백을 남길 때

테스트 번호, 바이옴과 타일 특징, 실제로 보낸 문장 또는 고른 문답, 모델 답변, 전후 그림을 함께 남기면 된다. 우선 1·2·5번만 확인하고, 문제가 보이면 나머지를 모두 반복하기보다 그 사례를 남겨도 충분하다.
