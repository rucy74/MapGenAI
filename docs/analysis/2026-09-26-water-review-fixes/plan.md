# Fable 검토 후속 — DEV 물가와 문답

기준 a4383a2, 복귀 태그 `dev-before-water-review-fixes-2026-09-26`. 사용자가 검토 결과에 이어 진행을 승인했다. 일반판/dist/main과 사용자 설정은 보존한다. 이번 구현에는 추가 Fable 또는 추천 API 호출을 사용하지 않는다.

## 변경 계약

- 물가 효과 허가는 자연 효과 영역에 겹치는 담수에서 최대6칸이다. 재질 거리는 그 물에서 4방향으로 이어진 담수만 따라가며, 이 연결 탐색도 같은6칸 범위와 명시적 보호 영역에 막힌다. 도형 안쪽 마스크만 거리로 사용하여 물의 완만한 가장자리를 놓치던 옛 문제로 되돌리지 않는다. 끝의4~6칸에서는 물가 폭과 외부 식생 효과를 줄인다.
- 새 물가에서 해당 바이옴이 쓰지 않는 Sand는 기존 Soil을 유지한다. 원래 Sand이거나 바이옴이 Sand를 쓰면 허용한다. Gravel은 바이옴이 쓰거나 바위3.5칸 안에 있을 때 허용한다. Mud의 기존 바이옴·기후·토양 조건은 유지한다. 자연 지형 내부 산기슭의 기존 바닥 규칙까지 바꾸지는 않는다.
- 물 채움 판정은 실제 복합 도형의 채움 우선순위를 따른다. union/sub/inter도 물을 그릴 수 있고, 최상위 dry fill이 덮으면 물로 안내하지 않는다. water 별칭 대소문자와 얕은 물 가장자리 재료를 통일한다. 저장된 null/none 및 정확한 도형 자동 효과는 유지한다.
- 문답은 원래 타일의 물과 직접 그린 물을 구분한다. 새 구도 교체에서는 교체할 저작 호수를 보존된 물가로 가정하지 않으며, ‘타일의 물만 유지’ 설명을 명시한다. 산 설명도 같은 원칙이다. 풍경/방어 우선순위가 명시적 산·물 금지를 무효화하지 못하도록 제출 문구에 적는다.

## 검증 순서

1. 순수 회귀: 실제 SDF 재료 출력과 물 판정 대조, 연결/분리/대각/보호/범위/완만한 가장자리, 한·영 문답 교체와 뒤로가기.
2. 실제 RimWorld 생성: 같은 제어 연못의 별개 물/연결된 물/보호 물/온천 비교. 통제 주입 영역을 명시하며 자연 생성 내용처럼 포장하지 않는다.
3. 온대·사막·한랭·북방림과 보호 영역, none/bypass 비교. 물/고도/동굴·기존 도로·전체 비율 영역을 보존하는지 실제 칸으로 대조한다.
4. 새 물가의 실제 프리뷰를 확인한다. 통과 횟수는 미관 보장이 아니며 사용자 사진의 상위 물 배치 문제 전체를 해결했다고 하지 않는다.

## 남는 범위

기존 자연 강/호수의 실제 윤곽을 추천 모델이 참조하는 기능, 모든 모드/바이옴, 실제 추천 모델의 모든 선호 준수, 최종 식물의 완전 동일성은 이번 완료 조건 밖이다. 문답의 ‘물이 있음’은 생성 계획 정보이며 도형의 모든 칸이 뒤의 편집 뒤에도 남는다는 보장은 아니다.
