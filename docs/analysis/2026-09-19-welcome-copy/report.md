# 시작 안내 문구 갱신

사용자는 예전의 기본 예시 화면을 첨부하며 현재 기능에 맞게 바꿀 필요가 있는지 물었다. 기존 목록은 추천이 마지막 예시에만 있고, 추천 그림의 확대·후보 지정 수정·번호 선택을 설명하지 않았다.

한글·영어 `MapGenAI_Welcome`을 추천으로 시작하는 흐름 → 직접 묘사 예시 → 후속 부분 수정 예시로 바꿨다. 실제 코드 내장 문구 `L10n.cs`와 두 언어의 Keyed XML을 동일하게 맞췄다. 일반 맵 생성 프롬프트, 모델 설정, 생성 엔진, 후보 수정 로직은 변경하지 않았다. 중국어/일본어 번역은 이번 범위가 아니다.

문구 예시는 현재 타일에 맞는 지형3개 추천, 후보 그림 확대/번호 선택, 선택 전 통로 자연스럽게 수정, 남쪽 출구가 있는 자연스러운 도넛 산, 중앙 호수/북쪽 산/남쪽 평지, 도넛 내부70% 비옥토다. 추천3번이 항상 통로라는 뜻이 아니라 번호 지정 수정의 예시다.

검증은 제품 빌드, 기존 오프라인 회귀150개, XML 파싱 및 코드/한영 XML의 실제 문자열 동일성 대조다. 이 문구만을 고정하는 새 회귀 테스트는 추가하지 않았다. 새 LLM 호출이나 완성맵 생성·실게임 화면 재검증은 하지 않았다. 이전 후보 교체 테스트의 미해결 네이티브 충돌은 이번 문구 변경으로 해결됐다고 주장하지 않는다.

- `dotnet build dev/Source/MapGenAI.csproj --no-restore --nologo`: 오류0, 기존 CS7035 경고1.
- `dotnet run --project dev/Source/Tests/TextToMap.Tests.csproj --no-restore`: [출력](tests.log), 150 PASS / 0 FAIL.
- [문구 대조 영수증](copy-check.json): C# 리터럴을 해석한 값과 XML의 줄바꿈을 해석한 값을 대조하고 최종 문구를 보관한다.
- `git diff --check`: 변경한 소스/XML/문서 검사.

되돌릴 기준은 직전 dev `60ca9868ed235195cf2e439b949137161f4b3b21`이다. 별도 기능 확장이 없는 문구 수정이므로 새 태그는 만들지 않고 기존 커밋 이력을 유지한다.
