# 자연지형 주변 바닥·식생 확인

개발판의 새 분지·골짜기·산기슭 평야가 대상입니다. 기존 저장 맵에는 자동으로 켜지지 않습니다.
아래 문장은 수동 확인용이며, 이번 빌드의 실제 API 응답 성공을 보장하는 테스트 기록은 아닙니다.

| 순서 | 입력 예시 | 확인할 점 |
| --- | --- | --- |
| 1 | 자연스러운 열린 분지 만들어 줘. 정착할 평지는 넓게. | 산기슭의 바닥이 작은 자갈 구간으로 이어지고 평지 대부분은 남는지 |
| 2 | 분지 안쪽 한편에 작은 연못도 만들어 줘. | 물 모양을 유지하면서 물가 주변 바닥이 자연스럽게 이어지는지 |
| 3 | 그 자동 바닥·식생 조화 효과만 꺼 줘. 산과 연못 모양은 유지해. | 산·연못 형태를 바꾸지 않고 주변 바닥 효과만 사라지는지 |
| 4 | 다시 주변 바닥과 식생을 자연스럽게 조화시켜 줘. | 같은 설정/시드에서 원래 효과가 돌아오는지 |
| 5 | 분지 안쪽 70%만 비옥한 토양으로 채워 줘. | 지정한 비율이 유지되고 나머지 30%도 자동 바닥 변경에서 제외되는지 |
| 6 | 그 안에 흙길을 깔아 줘. | 길과 다리가 자동 모래/자갈에 덮이지 않는지 |

강이 있는 타일과 온천이 있는 타일에서도 1번을 시도해 봅니다. 기존 강·온천의 모양은 유지하며,
자동 바닥 변경은 자연지형의 평지 안에 있는 일반 흙·모래에만 적용합니다.
기존 자갈·얼음·진흙·비옥토·특수 모드 토양 등은 이 효과가 덮지 않습니다.

사막에서는 숲을 억지로 늘리지 않습니다. 기본 게임의 사막 식생 규칙을 사용합니다.
Map Preview는 풀·나무를 그리지 않으므로, **식생은 실제 맵을 생성한 뒤** 확인합니다.
식물 종류·성장 가능 조건·이후 자연 재성장은 게임 규칙을 따릅니다.

이 단계는 이미 있는 지형 사이의 연결을 다듬는 작업입니다. 새 물줄기 연결이나 온천·유적의
배치 위치를 자동으로 다시 설계하는 단계는 포함하지 않습니다.
