# 자동 다리 직접 확인

MapGen AI [DEV]를 켜고 새 테스트 월드의 강이 있는 타일에서 확인한다. 세계지도에 도로가 없어도 된다. 강을 가로지르도록 방향을 지정하고, 강의 실제 방향이 반대라면 동서/남북을 바꾼다.

1. `서쪽 끝에서 동쪽 끝까지 일직선 흙길을 만들어 줘.`
2. `방금 흙길을 돌길로 바꿔 줘. 경로는 그대로 둬.`
3. `방금 길을 고대 아스팔트 고속도로로 바꿔 줘.`
4. `방금 추가한 길만 지워 줘.`
5. `서쪽에서 동쪽까지 강을 건너가는 흙도로를 놓아 줘. 필요한 곳은 다리로 연결해 줘.`

물 위에는 도로 재료가 아닌 게임 기본 나무 다리가 놓인다. 미리보기와 실제 생성 맵에서 양안의 길이 이어지는지 확인한다. 실제 맵에서 다리를 철거하면 원래 강물이 남아 있어야 한다. 도로 종류를 바꿔도 세계지도 도로는 추가되지 않는다.

얕은 연못을 피할 여유가 있는 맵에서 `연못을 피해 돌아가는 흙길을 만들어 줘`라고 하면 기존처럼 육지 우회로를 우선한다. 깊은 호수·깊은 바다·용암 또는 산을 관통하는 요청은 도로 전체를 적용하지 않고 경로 변경을 안내해야 한다.

원래 세계지도 도로는 Map Preview가 자체 생성하지 않으므로 기존 도로와 만나는 부분은 실제 맵에서 함께 확인한다. 추가한 지역 도로와 다리는 MapGen AI가 미리보기에 표시한다.
