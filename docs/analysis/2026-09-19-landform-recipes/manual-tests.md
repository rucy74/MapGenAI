# 칼데라·분지·협곡 요청 예시

현재 DEV에서 자동으로 검증한 요청이다. 직접 둘러보고 싶을 때 사용할 수 있으며 전부 다시 시험할 필요는 없다. 기본 예시는 강과 바다가 없는 내륙 타일에서 확인했다. 각각 새 타일 또는 초기화 후 시작한다.

## 1. 칼데라

> 자연스러운 칼데라 지형을 만들어 줘. 안쪽은 마른 평지로 해 줘.

마른 내부가 닫힌 산 고리로 둘러싸인다. 출구·물·폐허를 임의로 추가하지 않는다.

## 2. 분지와 후속 수정

아래 문장을 순서대로 입력한다.

1. 중앙에 남쪽으로만 열린 자연스러운 분지를 만들어 줘. 안쪽은 마른 평지, 출구는 폭 8칸으로 해 줘. 안쪽의 70%만 비옥토로 채우고 작은 폐허 두 개를 넣어 줘.
2. 분지 안쪽 평지만 조금 더 넓혀 줘. 바깥 산 경계와 자연스러운 윤곽 강도, 출구의 폭과 방향, 비옥토 비율, 폐허 개수는 그대로 둬.
3. 분지 전체를 오른쪽으로 맵 너비의 8%만큼 옮겨 줘. 내부 평지와 출구도 같이 옮기고 비옥토 70%와 폐허 두 개는 유지해 줘.
4. 남쪽 출구를 닫고 동쪽으로만 열어 줘. 기존 출구 폭과 분지, 내부 평지, 토양, 폐허는 그대로 유지해 줘.
5. 동쪽 출구 폭만 12칸으로 넓혀 줘. 다른 것은 그대로 둬.
6. 안쪽 비옥토만 50%로 줄여 줘. 나머지는 그대로 둬.
7. 동쪽 출구만 닫아서 완전히 둘러싸인 칼데라로 만들어 줘. 산 모양, 내부 평지, 비옥토 50%, 폐허 두 개는 그대로 둬.

2번은 바깥 산 경계를 유지하면서 안쪽 평지가 넓어져야 한다. 4번은 출구만 방향을 바꾸며, 7번은 출구만 사라져야 한다. 비율은 산비탈·건물 등을 제외한 사용 가능한 칸 기준이다.

## 3. 협곡

> 서쪽에서 동쪽으로 이어지는 자연스러운 협곡을 만들어 줘. 가운데는 걸어 다닐 수 있는 마른 통로로 해 줘.

산 덩어리 사이로 마른 통로가 나야 한다. 자연스러운 산 윤곽과 통로의 최소 폭을 구별한다. 바깥 평지까지 길을 칠하려면 전체 경로에 흙길을 이어달라고 명시한다.

## 4. 두 분지를 따로 수정·삭제

1. 왼쪽과 오른쪽에 서로 겹치지 않는 작은 자연스러운 분지를 하나씩 만들어 줘. 각각 안쪽은 마른 평지로 만들고 비옥토 70%, 작은 폐허 하나, 남쪽으로 폭 8칸 출구를 넣어 줘.
2. 오른쪽 분지 안의 비옥토만 30%로 줄여 줘. 왼쪽 전체와 양쪽 산 모양, 내부 평지, 출구, 폐허는 그대로 둬.
3. 오른쪽 분지에 추가한 산, 내부 평지, 비옥토, 폐허, 출구 설정을 전부 제거해 줘. 왼쪽 분지 전체는 그대로 유지해 줘.

왼쪽 설정은 모두 유지되고, 오른쪽은 추가한 설정이 함께 제거되어야 한다. 되돌리기로 직전 설정을 복원할 수 있다.

GL 전체 재현/전용 연동은 아니다. 산 밖 평지의 물이나 장애물을 보존하므로 맵 끝까지 같은 폭의 이동을 보장하지 않는다. [측정 범위와 한계](report.md).
