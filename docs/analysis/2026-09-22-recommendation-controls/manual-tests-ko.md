# 추천 취소·재추천·채팅 창 확인

MapGen AI [DEV]를 켜고 새 테스트 월드에서 확인하세요. 이번 변경은 추천 조작과 창 배치입니다.

1. `중앙에 작은 호수 만들어 줘`로 실제 설정을 하나 만든 뒤 `추천해 줘`.
2. **선택 안 함** 클릭. 호수는 그대로이고 추천 그림·적용 버튼만 사라져야 합니다. **되돌리기**를 누르면 앞서 만든 호수 변경을 되돌릴 수 있어야 합니다.
3. 다시 `추천해 줘` 후 **다시 추천받기** 클릭. 아무 후보도 적용하지 않고 새 후보를 요청해야 합니다. 버튼 대신 `다시 추천해 줘`도 가능합니다. 이 동작은 새 모델 요청을 사용합니다.
4. 새 후보가 보이면 **그림 접기** → **그림 펼치기**. 채팅 공간이 늘었다 돌아오며, 같은 그림이 즉시 다시 보여야 합니다. 이 조작은 모델을 호출하지 않습니다.
5. `2번을 좀 더 자연스럽게 해 줘`로 후보만 수정한 뒤 **2번 적용**. 수정된 후보만 적용되고 **되돌리기** 한 번으로 적용 전 맵으로 돌아가야 합니다.
6. 후보 수정 응답을 기다리는 동안 **선택 안 함** 클릭. 뒤늦게 도착한 응답이 후보나 맵을 되살리지 않아야 합니다.

입력창에 쓰던 문장은 위 관리 버튼을 눌러도 유지됩니다. 작은 화면에서는 채팅과 버튼이 잘리지 않도록 그림을 자동으로 숨길 수 있습니다. 창은 드래그로 이동할 수 있습니다.
