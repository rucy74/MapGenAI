# 산 출구와 전체 흙길 구별

최신 MapGen AI [DEV]를 로드한 뒤 사용할 문장이다. 아래처럼 추가·수정할 수 있다.

1. `맵 중앙에 도넛 모양 산을 만들어줘.`
2. `도넛 산 남쪽에 폭 8칸 출구를 뚫어줘. 안쪽과 바깥 평지의 원래 토양은 그대로 둬.`
   - 산 부분에만 출구가 생긴다. 산 밖이나 도넛 중심까지 일자 흙길을 칠하지 않는다.
3. `그 통로 폭만 12칸으로 넓혀줘.`
   - 산만 깎는 범위를 유지하면서 폭을 넓힌다.
4. `이제 그 통로를 남쪽 맵 끝까지 이어서 평지에도 전체 경로에 흙길을 만들어줘.`
   - 이때는 산 바깥까지 흙길이 이어진다.
5. `산 부분만 남기고 안쪽과 바깥 평지의 흙길은 지워줘. 경로와 폭은 유지해.`
   - 산 출구를 유지하며 평지의 원래 토양을 복원한다.

이미 만든 긴 흙길에는 5번 문장을 바로 사용할 수 있다. 기존 통로는 업데이트만 설치해도 자동 변경되지는 않는다. 되돌리기·저장·불러오기에도 적용 범위가 포함된다.

꺾인 통로 예시:

`산을 관통하는 폭 8칸 통로를 뚫어줘. 왼쪽 중앙에서 (0.35,0.7), (0.65,0.3)을 지나 오른쪽 중앙으로 이어줘. 산 밖 평지는 그대로 둬.`

자동 검증에서는 보관한 도넛/사각 산 상태와 통로 상태에서 각 추가·범위 수정·폭 수정을 실제 모델에 요청했다. 위 목록 전체를 하나의 연속 대화로 새 모델에 보낸 것은 아니다. 검증 범위와 실제 미리보기는 [보고서](report.md)에 있다.
