# 텍스트 추천 사용 예시

MapGen AI [DEV]에서 다음처럼 요청한다. 후보별 이미지 미리보기는 이번 버전에 없다.

| 상황 | 입력 | 기대 동작 |
|---|---|---|
| 아직 편집하지 않은 타일 | `그냥 추천해 줘` | 서로 다른 맵 구조를 기본3개 제안. 선택 전 미적용 |
| 선택 | `2번` 또는 `2번 적용` 버튼 | 표시한2번 설정만 적용. 선택 시 모델 재호출 없음 |
| 이미 분지를 만든 상태 | `추천해 줘` | 현재 분지에 어울리는 추가 요소를 제안. 산·기존 출구·토양 비율·폐허 재작성 방지 안내 |
| 범위 한정 | `농사하기 좋게 토양을 바꾸는 방법을 추천해 줘` | 새로운 전체 맵 대신 토양 관련 선택지 |
| 개수 한정 | `서로 다른 맵 두 개만 추천해 줘` | 2개 선택지 |
| 바로 생성 | `추천 말고 바로 왼쪽에 산, 오른쪽 아래에 작은 호수를 만들어 줘` | 추천 목록을 거치지 않고 기존 생성 경로 사용 |
| 영어 | `Recommend a map` | 영어 설명과 선택 버튼으로3개 제안 |

개수·다양성·기존 지형 보존의 의미 해석은 모델에 영향을 받는다. 설정 검사는 완성맵의 모든 공간 조건을 미리 증명하지 않는다. 최종 지형과 통로의 장애물은 생성 결과에서 확인한다. [자동 검증 기록](report.md).
