# 복합 요청·연속 수정 직접 테스트

MapGen AI [DEV]에서 새 내륙 타일을 고르고 아래 순서로 이어서 입력하세요. 각 단계의 미리보기를 확인하면 됩니다. 실제 폐허 벽은 맵을 생성했을 때 확인할 수 있습니다. 매 단계 초기화하지 마세요.

1. **함께 만들기**

   맵 중앙에 자연스러운 도넛 모양 산을 만들어 줘. 안쪽은 정착할 수 있는 마른 평지로 두고, 남쪽으로 폭 8칸짜리 출구 하나만 뚫어 줘. 출구는 산 부분만 깎고 바깥 평지는 그대로 둬. 도넛 내부에서 쓸 수 있는 땅의 70%만 비옥한 토양으로 채우고, 그 내부에 가로 9칸 세로 7칸 폐허를 2개 배치해 줘. 폐허가 출구를 막으면 안 돼. 이 조건들을 한꺼번에 적용해 줘.

2. **폭만 바꾸기**

   남쪽 출구의 폭만 12칸으로 넓혀 줘. 산 모양, 안쪽 비옥토 70%, 폐허 두 개와 나머지 설정은 유지해.

3. **비율만 바꾸기**

   비옥한 토양은 도넛 내부의 50%만 채워 줘. 산, 12칸 출구, 폐허 두 개는 그대로 둬.

4. **개수만 바꾸기**

   안쪽 폐허 개수만 3개로 늘려 줘. 크기와 나머지는 유지해. 출구는 막지 마.

5. **함께 이동하기**

   도넛 산과 내부 평지, 남쪽 출구를 함께 오른쪽으로 맵 너비의 10%만큼 이동해 줘. 비옥토 50%와 폐허 세 개는 계속 도넛 내부를 따라가게 해 줘. 다른 조건은 유지해.

6. **출구 방향 바꾸기**

   남쪽 출구는 닫고 동쪽으로 같은 폭 12칸 출구 하나만 뚫어 줘. 산 윤곽, 안쪽 비옥토 50%, 폐허 세 개는 유지해. 출구는 계속 산 부분만 깎아 줘.

7. **폐허만 삭제하기**

   폐허만 전부 지워 줘. 산, 내부 평지, 비옥토 비율, 동쪽 출구는 그대로 유지해.

8. **되돌리기·저장 확인**

   되돌리기로 폐허 세 개가 돌아오는지 확인하고, 저장 후 초기화·불러오기로 같은 배치 계획이 복원되는지 확인하세요.

비율은 산비탈·건물·월드 강과 도로 등을 제외한 사용 가능한 땅 기준입니다. 산 밖의 물이나 장애물은 그대로 남으며, 산에 낸 출구와 맵 끝까지의 넓은 도로는 서로 다릅니다. 응답은 모델/표현에 따라 달라질 수 있습니다.
