# 지역 맵 도로 수동 테스트

MapGen AI [DEV]의 새 대화에서 먼저 평지 타일로 확인하세요. 추가한 길은 Map Preview에 표시됩니다. 얇은 오솔길은 확대해서 확인하는 편이 좋습니다.

1. 맵 서쪽 끝에서 동쪽 끝까지 흙도로를 하나 만들어 줘.
2. 방금 만든 흙도로를 고대 아스팔트 도로로 바꿔 줘.
3. 그 도로만 지워 줘.
4. 맵 북쪽 끝에서 남쪽 끝까지 고대 아스팔트 고속도로를 만들어 줘.
5. 맵 서쪽에서 중앙을 지나 남쪽 끝으로 이어지는 돌길을 만들어 줘.
6. 중앙에 작은 원형 산을 만들어 줘. → 산을 돌아서 서쪽과 동쪽 끝을 연결하는 오솔길을 만들어 줘.

도로가 기존 산·물·건물을 밀어버리지 않는지 확인하세요. 공간이 부족하면 경유점 변경을 안내하는 것이 정상입니다. “산을 관통하는 통로”는 기존 산 절개 기능이고, 이번 “도로”는 마른 땅 위에 놓는 노면입니다.

추가·종류 변경·삭제마다 되돌리기도 확인할 수 있습니다. 세계지도에 길이 생기지는 않습니다. 원래 월드 도로가 있는 타일에서는 기존 길과의 교차 부분이 미리보기와 달라질 수 있습니다.

이번 범위는 오솔길·흙도로·돌길·고대 아스팔트 도로·고대 아스팔트 고속도로의 노면입니다. 다리·터널·가로등·방호벽 등 부속 시설은 자동 생성하지 않습니다.
