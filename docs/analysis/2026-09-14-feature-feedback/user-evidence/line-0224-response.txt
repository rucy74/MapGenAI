현재 게임에 로드된 자연 지형 재료(TerrainDef) 목록을 확인해 보았으나, '비옥한 화산 토양'이라는 이름의 고유 지형 Def는 존재하지 않습니다. 현재 사용 가능한 관련 지형 재료는 다음과 같습니다:

- **SoilRich** (기름진 토양 / 바닐라 비옥도 140%)
- **VolcanicRock** (화산암)
- **CooledLava** (식은 용암)
- **Soil** (일반 토양)

'비옥한 화산 토양'의 효과와 분위기를 내기 위해 **SoilRich(기름진 토양)**를 사용해 도넛 내부 중심의 약 70% 영역을 자연스러운 윤곽(`edge_roughness: "medium"`)으로 채워드릴까요? 아니면 다른 지형 재료를 원하시나요?
