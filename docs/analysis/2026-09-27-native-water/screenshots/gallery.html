온대림 · 이전 / 수정 DEV

같은 타일·시드·연못 지시를 사용했습니다.
새 물 생성 방식을 켠 것이 유일한 입력 차이입니다.

이전 DEV

기존의 윤곽과 바닥 조화 처리.

수정 DEV

원래 게임의 노이즈를 활용한 윤곽과 깊은 물 → 얕은 물 → 물가.

이번 수정은 물의 윤곽과 깊이, 물가를 함께 생성합니다. 이 표본의 온대림 기본 물가 재질은 모래입니다. 진흙을 모든 물 주변에 고정해서 두르지 않습니다.
실제 RimWorld + Map Preview가 생성한 PNG를 그대로 배치했습니다. 색상·지형 픽셀 보정 없음. 통제 시험용 표본이며, 추천 결과나 게임 화면 캡처는 아닙니다.

사막 · 이전 / 수정 DEV

같은 사막 타일·시드·연못 지시를 사용했습니다.
주변 사막은 두 버전 모두 같은 기반 지형입니다.

이전 DEV

기존 방식으로 배치한 시험용 연못.

수정 DEV

사막의 기본 물가 재질을 따릅니다. 물가를 자동 초원으로 바꾸지 않습니다.

모든 바이옴에 같은 진흙 띠를 붙이는 대신 게임이 해당 바이옴·특징에 선택한 물과 물가 재질을 사용합니다. 자연스러움의 완성도는 그림을 보고 판단해야 합니다.
실제 RimWorld + Map Preview가 생성한 PNG를 그대로 배치했습니다. 색상·지형 픽셀 보정 없음. 통제 시험용 표본이며, 추천 결과나 게임 화면 캡처는 아닙니다.

참조 · 게임 기본 호수와 오아시스

아래는 원래 게임의 특징 생성기를 실행한 결과입니다.
위 시험용 연못과 위치·크기·윤곽이 다른 참고 표본입니다.

기본 Lake · 온대림

게임이 정한 위치와 형태의 호수. 왼쪽 위 지도 바깥으로 일부 이어집니다.

기본 Oasis · 사막

게임의 오아시스 특징이 생성한 물과 주변 비옥한 땅.

이 두 그림은 수정 전후 비교가 아닙니다. 기본 호수·오아시스가 물의 깊이와 주변 재질을 연결하는 방식을 확인하기 위한 참조입니다.
