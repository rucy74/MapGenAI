# 자연지형 DEV 수동 테스트

이 문서는 로컬 `dev-natural-landforms` 변경용이다. 원본 저장소/게임 설치에는 아직 반영되지 않았다.
새 DEV 패키지로 테스트하며 기존 MapGen AI와 동시에 켜지 않는다. 일반 배포판에 설치하지 않는다.
아래 문장은 모델 해석을 포함한 사용자 테스트용이다. 자동 검증은 같은 형태의 설정을 직접 넣었으며
이 자연어 문장 모두에 대한 실제 API 응답을 확인했다는 뜻은 아니다.

## 1. 열린 분지 — 한 대화에서 차례대로

1. `자연스러운 열린 분지를 만들어 줘. 비대칭 산줄기가 넓은 정착지를 둘러싸고 남쪽으로 출구가 있으면 좋겠어.`
2. `출구와 전체 위치는 그대로 두고 안쪽 평지만 조금 넓혀 줘.`
3. `출구만 동쪽으로 옮겨 줘. 다른 산벽의 굴곡은 그대로.`
4. `출구를 조금 더 넓혀 줘.`
5. `분지 안쪽의 채울 수 있는 땅 중 70%만 비옥한 토양으로 채워 줘.`
6. `안쪽에 작은 폐허 하나를 넣어 줘.`
7. `이 분지 전체를 조금 왼쪽으로 옮겨 줘.`

확인: 산벽과 평지의 위치 관계 유지, 출구/내부 폭 별도 편집, 전체를 비옥토로 덮지 않음,
폐허가 실제 맵에 생성됨. 70%는 물·보호된 지형·건물 등 제외 후 채울 수 있는 칸 기준이다.
마지막 수정 전후에 되돌리기와 저장/불러오기도 확인한다.

## 2. 골짜기와 산기슭 — 초기화 후 각각

- `남북으로 넓게 굽이치는 자연스러운 골짜기를 만들어 줘. 양쪽에 산줄기가 있고 가운데는 정착할 만한 평지로.`
- 후속: `전체 모양은 유지하고 골짜기 폭을 조금 넓혀 줘.`
- `서쪽에 산줄기와 들쭉날쭉한 산기슭이 있고 동쪽으로 넓은 평야가 이어지게 만들어 줘.`
- 후속: `산이 북쪽에 있도록 돌려 줘.`
- 후속: `평지를 조금 더 넓혀 줘.`

강/해안 타일에서도 생성하고 기존 세계 강/바다 위치가 유지되는지 확인한다.
지형 자체의 평지가 연결되어도 기존 강·건물 등에 따라 보행 동선은 달라질 수 있다.

## 3. 추천과 기존 기능 보존

- `자연스러운 열린 분지, 넓은 골짜기, 산기슭 평야 중에서 서로 다른 정착지 후보를 추천해 줘.`
- `2번의 평지만 더 넓혀 줘.` → 다른 후보와 현재 적용된 맵이 바뀌지 않는지 확인.
- 마음에 드는 후보 없음/다시 추천/취소/선택/되돌리기 흐름 확인.
- `정확한 원형 산을 만들어 줘.`
- `별 모양 산을 만들어 줘.`
- `도넛 모양 산을 만들어 줘.` → `도넛 안쪽의 70%만 비옥한 토양으로 채워 줘.`
- 기존 정상 도로·다리·통로 테스트를 같은 타일에서 반복.

정확한 도형과 닫힌 도넛은 기존 생성기를 쓴다. 이 작업이 기존 도형을 새 자연지형으로 일괄 치환하지 않는다.
이미지 입력은 계속 꺼져 있다. 새 지형은 Geological Landforms의 원본 생성기/전체 목록을 구현한 것이 아니다.
