## 변경

- 빈 설정에서 자연 분지/골짜기처럼 전체 풍경을 맡긴 경우, 주 지형과 타일에 맞는 작은 요소를 첫 응답에 함께 계획하도록 한영 지침을 보완했다. 원래 물을 우선 활용하고, 적합한 온대림/초원에는 작은 얕은 연못을 고려한다. 건조/물 제외/산만 요청은 물을 추가하지 않는다.
- 바이옴의 바닥을 Soil/SoilRich 원판으로 덮지 않도록 명시했다. 후속 크기/출구/효과 수정에는 새 물이나 전역 비옥도·동식물 보너스를 끼워 넣지 않는다.
- 효과 끄기/켜기는 기존 landform의 details만 바꾸는 명시 예를 추가했다. 구버전 composite에는 해당 효과가 없으므로 몰래 지형을 교체하지 않는다.
- 재추천 지침에서 임의의 전역 수치 강화와 요청하지 않은 비옥토 채움 대신 국소적인 배치 차이를 우선한다. 이는 모델 지침이며 강제 품질 필터가 아니다.
- 설치 packageId가 Choco.MapGenAI.Dev이면 대화창/모드 설정 이름을 `MapGen AI [DEV]`로 표시한다. 생성 엔진·저장 데이터·기존 도형 수식은 변경하지 않았다.
