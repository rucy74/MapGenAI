# 추천 지도 비교 사용법

새 DEV 설치 후 게임을 재시작하고 MapGen AI에서 아래 순서로 확인한다. 자동 검증과 별개로 취향에 맞는 지형을 고르는 사용 예시다.

1. 아직 편집하지 않은 타일에서 `이 타일에 어울리는 서로 다른 지형 3개 추천해 줘`.
2. 응답 아래 지도 3개가 차례로 표시된다. 설명만 받았을 때와 달리 산·호수·통로 배치를 바로 비교할 수 있다.
3. 지도를 누르면 확대된다. 확대 창을 닫으면 세 후보 비교로 돌아온다.
4. 마음에 드는 지도의 `2번 적용` 버튼을 누르거나 채팅에 `2번`을 입력한다. 확대 창에서도 적용할 수 있다.
5. `되돌리기`로 선택 전 설정을 복원한다.
6. 도넛 산과 내부 토양 등을 만든 뒤 `지금 맵에 어울리는 보완안 3개 추천해 줘`로 기존 지형을 포함한 후보를 비교한다.

추천 답변을 받는 모델 호출은 기존과 같다. 이미 받은 설정을 그리는 미리보기·확대·번호 선택에는 추가 모델 호출이나 이미지 모델 비용이 없다. 생성 시간은 맵 크기와 설치 모드에 따라 달라진다.

미리보기는 지형과 배치를 보여 준다. 식물·건물 내부·적은 완성맵과 다를 수 있다. 실패한 후보는 안내를 표시하며 설명과 번호로 선택할 수 있다. 다른 후보의 미리보기는 계속 생성된다. 이미지 파일을 넣는 기능은 계속 중단 상태다.
