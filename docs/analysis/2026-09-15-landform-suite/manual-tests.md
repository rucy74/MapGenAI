# 통로 개선 직접 확인

최신 MapGen AI [DEV]로 게임을 다시 시작한 뒤 새 테스트 타일에서 확인한다. 원본 모드와 동시에 켜지 않는다. API 모델의 문장 해석은 달라질 수 있으므로 미리보기와 완성 맵을 함께 본다.

## 도넛 출구

1. `맵 중앙에 도넛 모양 산을 만들어줘.`
2. `도넛 산 안쪽 중앙에서 남쪽 맵 끝까지 걸어나갈 수 있도록 최소 8칸 폭의 마른 흙길 통로를 뚫어줘. 나머지 산은 그대로 둬.`
3. `그 통로의 폭만 12칸으로 넓혀줘. 경로와 다른 지형은 유지해.`
4. 되돌리기 → 다시 8칸인지, 산 전체가 없어지지 않는지 확인.
5. 저장 → 초기화 → 불러오기 후 같은 경로·폭인지 확인.

## 꺾인 협곡

1. `맵 중앙 70% 정도를 차지하는 넓은 정사각형 산을 만들어줘.`
2. `산을 관통하는 폭 8칸의 마른 흙길을 만들어줘. 왼쪽 중앙에서 시작해서 (0.35,0.7), (0.65,0.3)을 순서대로 지나 오른쪽 중앙까지 이어줘. 나머지 산은 유지해.`

좌표는 왼쪽 아래(0,0), 오른쪽 위(1,1)이다. 꺾이는 부분에서도 길이 끊기거나 좁아지지 않는지 본다. 물길을 요청한 것이 아니므로 호수가 나오면 실패다.

1차 생성 문장은 설정 준비용 예시다. 자동 검증에서는 보관한 고리/정사각형 산 설정 위에 통로 문장을 적용했다. 폭 변경은 코드 편집·저장 회귀를 검사했으며 위의 모든 연속 문장을 별도로 새 모델에 보낸 것은 아니다.

통로 바닥에 건물·잔해 등이 남았다는 안내는 실제 장애물 검사 결과다. 월드 바다/강 위에 마른 육교를 강제로 놓지는 않는다. 반도·군도·지붕 있는 동굴은 이번 완료 범위가 아니다.
