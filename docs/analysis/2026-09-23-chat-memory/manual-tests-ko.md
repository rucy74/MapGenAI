# MG31 — DEV 후속 대화 확인

일반 MapGen AI를 끄고 **MapGen AI [DEV]**만 켭니다. 기존 설정/API 키는 유지됩니다. 이번 개선은 일반판에는 아직 없습니다.

## 같은 대화창에서 이어서

먼저 산이나 깊은 호수가 중앙을 막지 않는 평지 타일에서 아래 문장을 순서대로 보냅니다.

1. `맵의 북쪽에서 남쪽, 서쪽에서 동쪽으로 십자가 모양 흙길 두 개를 깔아줘.`
2. `아니 완전한 십자가 모양. 십자가가 만나는 점이 맵의 중심.`
3. `이번엔 북동쪽에 작은 자연스러운 호수 하나 추가해 줘.`
4. `아까 만들었던 십자가 흙길 두 개만 돌길로 바꿔줘.`

2번은 기존 두 도로의 위치·직선 여부를 고쳐야 하며 산을 새로 만들면 안 됩니다. 4번은 북동쪽 호수를 남기고 도로 재료만 바꿔야 합니다. 되돌리기를 누른 후 `현재 맵에 무엇이 있는지 설명해 줘`를 보내면 취소된 수정을 현재 상태로 말하지 않아야 합니다.

추천 → 후보 한 개 수정 → 번호/버튼으로 선택 → 후속 부분 수정도 확인할 수 있습니다. 후보 선택 전에는 맵이 바뀌지 않고, 선택하면 수정한 버전 전체가 적용됩니다.

## 강이 있는 타일

`맵 정중앙에서 정확히 교차하는 일자 십자 흙길 두 개를 만들어 줘. 중간 강은 다리로 건너줘.`

다리를 놓을 수 있는 물에는 기본 나무 다리가 생깁니다. 직선 위의 산·깊은 호수·바다·용암·건물과 물 위 끝점은 배치 실패 이유가 될 수 있습니다. 이때 산으로 바뀌거나 물이 지워져서는 안 됩니다. 평탄화나 지형 제거가 필요하면 별도로 명시해야 합니다.

## 자동 요약

일반적인 짧은 테스트로는 발동하지 않는 것이 정상입니다. Gemini 모델 한도가 큰 경우 대화가 상당히 길어져야 입력 예산80%에 도달합니다. 요약에는 추가 모델 호출 비용이 있으며, 최근3유저턴은 원문으로 남깁니다. 고급 입력 예산을 너무 낮게 설정하면 기본 지침만으로도 한도를 넘어 요청이 중단될 수 있습니다. 요약 실패는 원문을 지우지 않습니다. **초기화와 창 닫기는 대화가 끝나는 동작**입니다.
