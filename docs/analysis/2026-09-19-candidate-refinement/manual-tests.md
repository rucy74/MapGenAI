# 추천 후보를 보고 수정하기

1. `이 타일에 어울리는 지형 3개 추천해 줘.`
2. 통로가 있는 후보가3번이라면 `3번 통로는 곧은 방향을 유지하고 가장자리만 자연스럽게 울퉁불퉁하게 해 줘.`
3. 1·2번 지도는 유지되고3번 지도만 새로 표시된다. 현재 맵은 아직 바뀌지 않는다.
4. `3번 통로 가장자리를 좀 더 거칠게 해 줘.` 또는 `3번 통로 다시 반듯하게 해 줘.`
5. `1번에 비옥도를 조금 높여 줘.`로 다른 후보의 일반 설정도 수정할 수 있다.
6. 마음에 들면 번호나 적용 버튼을 선택한다. 선택 후 `되돌리기` 한 번이면 후보 수정 전부터 유지하던 실제 맵 설정으로 돌아간다.

후보 번호는 실제 추천 결과에 맞춘다. 지형3개가 항상 같은 순서로 나오는 것은 아니다. 정확한 직선은 기본값이며 자연스럽다는 요청에만 가장자리를 확장한다. 최소 통행폭과 전체 방향을 유지하고, 산에 출구를 낼 때는 기존처럼 산 밖 평지를 보존한다.

요청을 해석할 때는 모델을 호출한다. 작은 지도 생성·확대·후보 선택은 로컬 처리다. 후보를 무시하고 실제 맵을 바로 편집하려면 `추천 말고 현재 맵에 바로 원형 산 만들어 줘.`처럼 명시한다. 이미지 파일 입력은 계속 중단되어 있다.
