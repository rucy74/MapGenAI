# 추천 그림 피드백 수동 확인

이 문서는 새 DEV 패키지를 설치한 뒤 확인할 항목이다. 현재 원본 게임 설치에는 아직 반영되지 않았다. 기존 일반 MapGen AI와 DEV를 함께 켜지 않는다.

1. **그림에서 수정**: 추천받은 뒤 한 후보의 `수정` → `너무 인공적이에요` → 확인. 해당 후보만 다시 그려지고 나머지 후보·현재 맵은 유지되는지 확인한다. 새 결과의 미관은 별도로 평가한다.
2. **취소**: 채팅 입력창에 문장을 작성한 채 수정/재추천 창을 열고 취소한다. 후보·입력 초안·맵·되돌리기가 유지되어야 한다.
3. **재추천**: `다시 추천받기` → `후보들이 너무 비슷해요`. 확인 전까지 기존 후보가 유지되고, 확인 뒤 다른 후보를 요청해야 한다. 실제 맵에는 적용하지 않는다.
4. **적용 표현의 혼입**: 후보 수정이나 전체 재추천의 자유입력에 `추천 말고 현재 맵에 바로 적용해 줘`를 넣어 본다. 해당 창에서는 후보 작업만 허용한다. 실제 맵 편집은 창을 닫고 일반 채팅에서 요청한다.
5. **선택적 추가 질문**: 피드백 선택 → `AI에게 추가 질문 받기 · API 사용`. 1~2개 객관식 질문이 나와야 한다. 전부 선택하기 전에는 확정되지 않는다. 건너뛰면 직접 피드백으로 돌아간다. 추가 질문과 이후 추천에 각각 API 요청이 발생한다.
6. **질문 중 취소**: 추가 질문을 기다리는 동안 취소한다. 뒤늦게 응답이 와도 닫힌 질문 창이나 후보를 바꾸면 안 된다.
7. **실패 후보**: 배치 실패한 후보는 번호가 그대로이고 `수정 필요`로 표시되어야 한다. 적용 버튼과 `3번` 같은 채팅 선택은 모두 차단되어야 한다. `실패한 배치를 고쳐 주세요`로 수정을 요청할 수 있어야 한다.
8. **정상 선택**: 확인된 정상 후보를 적용하고 한 번 되돌린다. 선택 전 맵이 복원되어야 한다. 미리보기 모드가 없을 때에는 기존처럼 설명을 보고 선택할 수 있어야 한다.
9. **작은 화면·영어**: 그림 접기/펼치기, 확대 → 수정, 긴 실패 이유와 긴 질문 보기, 영어의 Apply/Refine 버튼을 확인한다. 글자가 겹치거나 채팅 공간을 과도하게 차지하면 화면 크기와 함께 기록한다.

작은 연못이 잘 보이는지, 윤곽이 자연스러운지, 살기 좋은 맵인지까지 자동 합격 판정하는 기능은 아니다. 새 물 의도 25칸 이상인데 실제 물이 0칸인 경우만 별도 실패로 감지한다.
