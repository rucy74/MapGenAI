# MapGen AI DEV — 다양한 텍스트 풍경 테스트

작성: 2026-09-26. 대상은 **MapGen AI [DEV]**입니다. 일반판과 DEV를 함께 켜지 않습니다. 아래는 사용자가 직접 비교할 수 있도록 만든 **테스트 입력과 합격 기준**이며, 모든 문장이 이미 성공했다는 결과표가 아닙니다. 이번 개발의 실제 자동·모델·맵 검증 범위는 해당 작업 보고서와 구별합니다.

이 목록은 사용자가 요청한 선택형 테스트 자료입니다. 전부 수행할 필요는 없습니다. 먼저 핵심 10개에서 서로 다른 타일·구도를 골라 보세요. 코드는 수치와 보존 여부를 검사할 수 있지만, 보기 좋고 살고 싶은 맵인지와 사용자의 전체 모드 조합에서 느껴지는 결과는 별도 판단이 필요합니다.

## 사용하는 방법

- **독립**이라고 적힌 항목은 새 타일 또는 초기화한 상태에서 시작합니다. **후속**은 바로 앞에 지정한 요청을 이어서 보냅니다.
- 추천은 후보를 선택하기 전에는 현재 맵이 바뀌지 않아야 합니다. 마음에 안 들면 선택하지 않아도 됩니다.
- 평지·강변·해안·사막은 한 곳에서 억지로 모두 시험하지 않고 실제 월드 조건이 맞는 타일을 사용합니다. 처음 비교는 250×250 크기가 편합니다.
- `기존 X 유지`를 매번 붙이지 않았습니다. 부분 수정에서는 말하지 않은 산·물·길이 유지되는지 자체가 검사 대상입니다.
- Map Preview는 풀·나무의 실제 밀도, 최종 건물 배치, 주민·상인의 실제 이동까지 보여주지 않습니다. 마음에 드는 후보만 실제 맵으로 생성해 확인하면 됩니다.
- 예쁜 결과가 나와도 요청을 어겼다면 별도 실패입니다. 반대로 불가능한 월드 조건을 설명하며 맵을 그대로 두는 것은 정상입니다.
- 자동 관계 배치는 가장자리 전환까지 감싼 직사각형 전체가 들어가는지 보수적으로 검사합니다. 좁고 굽은 곳에서는 육안상 들어갈 듯해도 실패할 수 있습니다. 크기를 몰래 줄여 넣는 대신 배치 불가가 표시되는지 구별합니다.

## 추천·문답·재추천

문답은 채팅에 질문해 달라고 쓰는 방식이 아니라 **취향에 맞춰 추천받기 / 취향 문답** 버튼으로 엽니다. 기본 질문은 우선순위, 산, 물, 생활 공간의 연결 방식, 특별한 지형 선호, 지형 특징 포함 여부입니다. 특별한 풍경을 고르면 관심 분야를 한 번 더 묻고, 이미 직접 만든 지형이 있으면 처음에 기존 구도 다듬기와 새 구도 비교를 구별합니다. 총 6~8문항이며 중간에 상관없음·건너뛰기 또는 지금 답한 내용으로 마무리할 수 있습니다.

| ID | 조건 | 요청 / 행동 | 확인점 |
|---|---|---|---|
| D01 | 독립, 같은 타일 | `추천해 줘` → 미선택 상태로 `다시 추천해 줘`를 두 번 | 여러 회차가 같은 세 종류·같은 구도만 반복되는지. 회전·연못 크기만 다른 것은 다양성 미흡. |

| D03 | 후보 표시 | `2번은 좋은데 물이 너무 커. 물만 줄여 줘` | 2번 후보만 편집, 다른 후보·현재 맵 보존. |

이번 확장은 이름별 완제품 지형을 늘리기보다, 같은 곡선과 영역 관계를 서로 다른 재료·구도에 쓰는 방향입니다. 아래는 그 목적에 맞춘 도전 사례이며 특히 **아직 해보지 않은 조합의 결과를 성공으로 간주하지 않습니다.**
