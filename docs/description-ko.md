# MapGen AI — 모드 소개와 사용법

> 2026-09-13 작성·갱신. `dev`의 이미지 개선과 후속 설정 UI 수정을 포함한 **MapGen AI [DEV]** 기준입니다. 기존 기능과 이번 개발판의 추가·개선 사항을 함께 정리한 사용자용 문서입니다.

## 한눈에 보기

**원하는 지형을 말로 설명하거나 참고 맵 이미지를 가져와, RimWorld의 정착지를 만들어 보세요.**

MapGen AI는 월드맵에서 선택한 타일의 지형을 AI 대화로 조정하는 모드입니다. 산맥과 호수의 위치, 강의 방향, 토양과 식생 등을 요청하고, Map Preview에서 생성 결과를 확인하며 다듬을 수 있습니다.

이번 개발판에는 **참고 이미지에서 지형을 가져오는 기능**과 **이미 만든 특징을 유지하면서 필요한 부분을 수정하는 편집 개선**이 포함되었습니다. 처음부터 모든 조건을 완벽하게 적을 필요 없이, 결과를 보고 다음 요청을 이어갈 수 있습니다.

## 기본 기능

- **자연어로 지형 만들기:** 산맥, 협곡, 중앙 호수, 고리 모양 산지처럼 원하는 지형과 배치를 설명합니다. 별·하트·초승달처럼 여러 도형을 조합한 지형도 요청할 수 있습니다.
- **강과 지면 조정:** 강의 방향·위치·직선 여부를 바꾸고, 지정 영역에 모래·비옥토·습지·진흙·얼음 등을 적용합니다.
- **맵 환경 조정:** 비옥도, 식생·동물·광석 밀도, 암석 종류, 동굴 등 생성 설정을 조절합니다.
- **고대 위협과 폐허 설정:** 고대 위협 밀도와 폐허·고대 유적 밀도를 구별해 요청할 수 있습니다. 밀도는 생성 개수를 정확히 지정하는 기능이 아니며, 폐허 설정의 효과는 맵 생성 방식에 따라 제한됩니다.
- **Odyssey 지형 특징:** DLC가 있으면 온천·피오르드·오아시스 등 해당 타일에서 사용할 수 있는 특징을 대화로 추가하거나 제거할 수 있습니다.
- **Map Preview 연동:** 변경한 설정으로 생성되는 맵을 확인하고 후속 요청으로 다듬습니다.
- **되돌리기·초기화·프리셋:** 이전 수정으로 돌아가거나 타일의 기본 상태로 초기화하고, 마음에 드는 설정을 저장해 다시 불러옵니다.

## 이번 개발판에서 추가·개선된 점

### 기존 지형을 유지하는 연속 편집

일반적인 수정 요청은 바꿀 항목을 현재 설정에 반영합니다. 산을 만든 뒤 호수를 추가하거나, 호수의 크기만 바꾸거나, 특정 도형을 이동·회전·삭제하는 편집을 개선했습니다. 타일별 설정과 이미지 지형을 되돌리기·프리셋 저장에 함께 포함합니다.

예를 들어 다음처럼 차례로 요청할 수 있습니다.

1. “북쪽에 산맥을 만들고 중앙에는 큰 호수를 넣어줘.”
2. “산맥은 그대로 두고 호수만 조금 작게 해줘.”
3. “그 호수를 오른쪽으로 조금 옮겨줘.”
4. “고대 위협 밀도를 1.8로 설정해줘.”

실제 변경 내용과 실패 안내도 정비했습니다. 잘못된 AI 응답은 적용하지 않고, 취소한 요청의 늦은 응답이 나중에 설정을 덮어쓰지 않도록 처리합니다. 요청 해석은 선택한 모델과 표현에 따라 달라질 수 있으므로 결과는 미리보기에서 확인합니다.

### 참고 이미지 → 맵 지형

**PNG·JPEG로 된 맵 이미지를 불러와 산, 물, 평지 등의 배치를 지형으로 변환할 수 있습니다.** 대표적인 입력은 다음과 같습니다.

- RimWorld Map Preview 이미지
- 웹에서 구한, 산과 물의 배치가 잘 보이는 탑다운 지도·맵 그림
- GPT나 Gemini 등으로 미리 만든 RimWorld 스타일 맵 이미지

손으로 직접 그리거나 정해진 색상표를 맞출 필요는 없습니다. 추가 설명도 선택 사항입니다. 사람이 봐도 산·물·빈 공간의 배치를 읽을 수 있는 참고 이미지가 대상입니다.

기본 방식은 원본의 색상과 영역을 AI가 지형 종류로 분류하고, 축소해 읽은 원본 배치를 맵에 반영합니다. **“윤곽을 AI가 다시 추론”** 옵션을 켜면 AI가 더 단순한 도형으로 해석하는 방식을 사용할 수 있습니다. 정해진 팔레트로 그린 이미지용 **“팔레트 색상 가져오기”**도 제공됩니다.

### 잘못 읽은 영역을 직접 교정

원본과 지형 분류도를 나란히 보면서 연결된 영역을 클릭해 선택할 수 있습니다. 선택한 영역은 버튼이나 **“영역 채팅 수정”**으로 자연 지형·산·물·얕은 물·토양·비옥토·모래·습지·진흙·얼음 중 하나로 바꿉니다.

예를 들어 산을 토양으로 잘못 읽었다면 해당 영역을 선택해 **산**으로 변경하면 됩니다. 이미지 창 안의 수정은 **“수정 되돌리기”**로 취소할 수 있고, **“타일에 적용”**을 눌러 맵 설정에 반영합니다.

이 창의 분류도는 지형 해석 결과입니다. **최종 생성 결과는 적용 후 Map Preview에서 확인합니다.**

### 이미지와 추가 도형의 높이 우선

**“이미지·추가 도형의 높이를 월드 지형보다 우선”** 옵션은 참고 이미지에서 평지로 읽은 곳에 원래 타일의 산이 남거나, Odyssey의 지형 특징이 이미지 배치를 크게 바꾸는 문제를 줄입니다. 이미지 위에 추가한 지형 도형도 함께 반영합니다.

새로 가져온 이미지에서는 기본으로 켜집니다. 이전에 저장한 이미지 설정은 종전 동작을 유지합니다. **자연 지형**으로 지정한 영역은 원래 월드 지형을 사용하며, 동굴·광물·식생 등 높이 이외의 생성 요소는 계속 결과에 영향을 줄 수 있습니다. 옵션을 끄면 토양은 기존 높이를 유지하고, 월드 지형이 이미지의 산·물 높이도 바꿀 수 있습니다.

### 모델 선택 개선

개발판의 Gemini 기본 모델은 **Gemini 3.8 Flash**입니다. 간편 설정에서 **“모델 목록 불러오기”**를 눌러 API에서 조회한 모델을 선택하거나, 모델명을 직접 입력할 수 있습니다. 두 모델로 제한하지 않습니다. 고급 설정의 공급자별 모델 선택과 기존 지정값도 유지합니다.

고급 설정 화면이 깨지던 UI 영역 종료 오류를 수정했습니다. 조회에 실패하면 현재 모델 선택을 유지하고 오류 안내를 표시하며, 목록을 다시 불러올 수 있습니다.

Gemini, OpenAI, OpenRouter 및 OpenAI 호환 로컬 서버 연결을 지원합니다. **이미지 AI 해석에는 선택한 모델과 서버의 이미지 입력 지원이 필요합니다.** 모든 공급자·모델에서 같은 품질이 검증된 것은 아닙니다.

## 시작하기

1. **Harmony**, **Map Preview**, **MapGen AI [DEV]**를 활성화합니다. 현재 개발 테스트 패키지는 RimWorld **1.6용**이며, 기존 **MapGen AI**와 DEV 중 사용할 쪽 하나를 활성화합니다.
2. **모드 설정 → MapGen AI**에서 공급자·모델을 선택하고 API 키를 설정합니다. 로컬 모델을 쓰는 경우 서버 주소와 모델을 설정합니다.
3. 월드맵에서 정착할 타일을 선택하고 Map Preview 옆의 **AI Map Gen** 버튼을 엽니다.
4. 원하는 지형을 입력하고 생성 결과를 확인합니다. 이후 대화로 필요한 부분을 수정합니다.

이미지를 사용할 때는 대화창의 **“이미지 지형”**을 엽니다. PNG/JPEG 파일 경로를 붙여넣고 **“PNG/JPEG 열기” → “AI로 해석”**을 누릅니다. 필요하면 영역을 교정한 뒤 **“타일에 적용”**하고 Map Preview를 확인합니다. 이미지 윗부분은 북쪽으로 해석합니다.

## 현재 범위와 한계

- **지형 배치를 참고해 맵을 생성합니다.** 원본 화면을 픽셀 단위로 복제하거나 이미지 속 건물·가구·아이템까지 재현하는 기능은 아닙니다.
- 비슷한 색의 산과 토양, 물가의 가는 경계는 잘못 분류될 수 있습니다. 이미지 축소나 작은 맵 크기로 좁은 강·통로가 사라질 수도 있습니다.
- 이미지 속 글자, UI, 작은 삽입 그림이 지형으로 섞일 수 있습니다. 가능하면 맵 영역이 크게 보이는 이미지를 사용합니다.
- 이미지 영역 교정은 **지형 종류 변경**까지 지원합니다. 외곽선을 직접 끌어 옮기거나 브러시로 다시 그리는 기능은 아직 없습니다. 자연어로 추가한 도형의 이동·크기 수정과는 구별됩니다.
- 외부에서 AI로 만든 맵 이미지를 가져올 수 있습니다. 모드 안에서 GPT/Gemini에 새 그림을 생성시키는 기능은 아직 없습니다.
- 분위기만 있는 풍경사진에서 보이지 않는 맵 구조까지 복원하는 용도로 설계하지 않았습니다.
- 현재 DEV는 개발·검증 중입니다. 다양한 모드 조합, 실제 오래된 사용자 세이브의 전환, RimWorld 1.5에서의 새 기능은 추가 검증이 필요합니다. 새 프리셋을 이전 버전에서 읽는 것도 보장하지 않습니다.
- 기존 UI에는 한국어·영어·일본어·중국어 간체 번역이 있으나, 새 이미지 창은 현재 한국어·영어 문구를 제공합니다.
