# MapGen AI — 모드 소개와 사용법

> 2026-09-19 갱신. 자연스러운 도형 윤곽과 월드 지리 조건에 따른 특징 편집을 포함한 **MapGen AI [DEV]** 기준입니다. 실제 재료 채움, 지형을 기준으로 한 구조물 배치와 게임 기본 고대 위협 생성을 지원합니다. 현재는 텍스트 생성·수정·삭제에 집중하며, 이미지 입력·해석·팔레트·생성 효과는 일시 중단했습니다. 저장된 이미지 데이터는 보존합니다.

## 한눈에 보기

**원하는 지형과 폐허의 위치를 말로 설명해 RimWorld의 정착지를 만들어 보세요.**

MapGen AI는 월드맵에서 선택한 타일의 지형을 AI 대화로 조정하는 모드입니다. 산맥과 호수의 위치, 강의 방향, 토양과 식생 등을 요청하고, Map Preview에서 생성 결과를 확인하며 다듬을 수 있습니다.

이번 개발판에는 **실제 용암 등 재료 채움**, **섬 안·강가·산기슭의 폐허와 고대 위협 배치**, **이미 만든 특징을 유지하는 연속 편집**이 포함되었습니다. 처음부터 모든 조건을 완벽하게 적을 필요 없이, 결과를 보고 다음 요청을 이어갈 수 있습니다.

## 기본 기능

- **자연어로 지형 만들기:** 산맥, 협곡, 중앙 호수, 고리 모양 산지처럼 원하는 지형과 배치를 설명합니다. 별·하트·초승달처럼 여러 도형을 조합한 지형도 요청할 수 있습니다.
- **강과 지면 조정:** 강의 방향·위치·직선 여부를 바꾸고, 지정 영역에 모래·비옥토·습지·진흙·얼음 등을 적용합니다.
- **맵 환경 조정:** 비옥도, 식생·동물·광석 밀도, 암석 종류, 동굴 등 생성 설정을 조절합니다.
- **고대 위협과 폐허 설정:** 고대 위협 밀도와 폐허·고대 유적 밀도를 구별해 요청할 수 있습니다. 밀도는 생성 개수를 정확히 지정하는 기능이 아니며, 폐허 설정의 효과는 맵 생성 방식에 따라 제한됩니다.
- **Odyssey 지형 특징:** DLC 및 제공 모드가 있으면 온천·피오르드·오아시스 등 실제 조건에 맞는 특징을 대화로 추가하거나 제거할 수 있습니다. 월드 강·해안 연결은 유지합니다.
- **Map Preview 연동:** 변경한 설정으로 생성되는 맵을 확인하고 후속 요청으로 다듬습니다.
- **되돌리기·초기화·프리셋:** 이전 수정으로 돌아가거나 타일의 기본 상태로 초기화하고, 마음에 드는 설정을 저장해 다시 불러옵니다.

## 이번 개발판에서 추가·개선된 점

### 정착 맵에 도로 만들기

“서쪽에서 동쪽으로 흙도로”, “방금 길을 고대 아스팔트 도로로 바꿔 줘”, “산을 돌아가는 오솔길”처럼 요청할 수 있습니다. 오솔길·흙도로·돌길·고대 아스팔트 도로·고대 아스팔트 고속도로의 노면을 지원하고, 추가한 길은 Map Preview에도 표시됩니다. 세계지도 도로 연결은 변경하지 않습니다.

종류에 따라 게임 기본 폭과 재료를 사용합니다. 강·바다·산을 자동으로 밀어버리지 않으며, 공간이 부족하면 경유점 변경을 안내합니다. 다리·터널·가로등·방호벽은 자동 생성하지 않습니다. 원래 월드 도로와 겹치는 구간은 기존 바닥을 유지하므로 실제 맵과 미리보기의 모습이 다를 수 있습니다. [테스트 문장](analysis/2026-09-19-local-roads/manual-tests-ko.md)

### 여러 조건을 함께 요청하고 일부만 수정하기

“자연스러운 도넛 산, 남쪽 8칸 출구, 내부 비옥토 70%, 내부 폐허 두 개”처럼 함께 요청할 수 있습니다. 폐허를 산벽과 구별해 산에 둘러싸인 빈 내부에 배치하고, 지정한 출구 경로에는 놓지 않도록 보완했습니다. 비옥토 비율을 바꿔도 폐허의 기준 영역은 산의 내부로 유지됩니다.

이어서 “출구 폭만 12칸”, “비옥토만 50%”, “폐허만 세 개”, “산과 내부·출구를 함께 오른쪽으로 이동”처럼 수정합니다. 명시적으로 마른 정착지를 원한다면 “안쪽은 마른 평지로”를 포함하세요. 모델이 내부 평탄화를 별도 작업으로 지정하도록 안내하며, 모든 문장의 해석을 보장하지는 않습니다. 산만 깎는 출구는 바깥의 원래 물·평지를 보존하므로 맵 끝까지 같은 폭으로 걸을 수 있다는 뜻은 아닙니다. [검증 범위와 한계](analysis/2026-09-19-compound-plan/report.md).

### 연결 지점과 칸 수로 지정하는 마른 통로

칼데라·열린 분지·협곡을 짧은 지형 설명으로 요청할 수 있도록 구성 안내를 보강했습니다. 예: “자연스러운 칼데라 지형을 만들어 줘. 안쪽은 마른 평지로 해 줘.” 또는 “남쪽으로 열린 자연스러운 분지를 만들어 줘. 안쪽은 정착할 수 있는 마른 평지로 해 줘.” 이어서 내부 평지만 넓히거나 출구 방향만 바꾸고, 여러 분지 중 하나만 수정·삭제할 수 있습니다. 기존 산·영역·통로 기능을 조합하며 GL 원본 생성기/전체 지형과 직접 연동하지는 않습니다. [검증한 요청 예시](analysis/2026-09-19-landform-recipes/manual-tests.md)와 [검증 범위](analysis/2026-09-19-landform-recipes/report.md)를 참고하세요.

“도넛 산 남쪽에 폭 8칸 출구를 뚫어줘”처럼 요청할 수 있습니다. 산에 출구·통로를 뚫는 요청은 경로상의 산 부분만 깎고, 도넛 안쪽과 산 바깥 평지의 원래 토양은 유지합니다. 경계는 생성 시점의 실제 산 높이로 계산합니다. 경로에 산이 없으면 평지를 바꾸지 않고 안내합니다.

“안쪽 중앙에서 남쪽 맵 끝까지, 평지에도 폭 8칸 흙길을 이어줘”는 전체 경로에 흙길을 만듭니다. 꺾이는 길은 지나갈 지점을 순서대로 지정합니다. “8칸”과 “맵 너비의 8%”는 다른 요청입니다. 기존에 저장한 통로는 원래의 전체 경로 적용을 유지합니다.

후속으로 “그 통로 폭만 12칸으로 넓혀줘”, “그 통로를 없애줘”를 요청하거나 되돌리기·저장을 사용할 수 있습니다. “산 부분만 남기고 바깥 흙길은 지워줘”로 적용 범위를 바꿀 수도 있습니다. **“곧은 방향은 유지하고 가장자리만 자연스럽게 울퉁불퉁하게 해 줘”**라고 하면 최소 통행 폭은 유지하면서 양옆을 불규칙하게 넓힙니다. “살짝”, “더 거칠게”로 강도를 조절하고 “다시 반듯하게”로 정확한 통로로 돌아갈 수 있습니다. 생략하면 기존 반듯한 통로를 유지합니다. 명시한 통로는 다른 사용자 지형보다 나중에 산을 깎으므로 다시 막으려면 통로 자체를 수정하거나 삭제합니다. 산 부분만 깎는 경우에는 보존한 평지·물 위의 이동 가능 여부까지 보장하지 않습니다.

월드 강·바다를 마른 육교로 덮거나, 두꺼운 산 지붕을 남긴 동굴을 만드는 기능은 아닙니다. 생성기가 통로에 건물·잔해를 놓아 요청한 바닥 일부가 막히면 남은 장애물을 알립니다. 다른 생성기의 모든 배치를 강제로 지우지는 않습니다. [대표 지형과 기존 기능 보존 검증](analysis/2026-09-15-landform-suite/report.md)에 범위와 남은 한계를 기록했습니다.

### 기존 지형을 유지하는 연속 편집

일반적인 수정 요청은 바꿀 항목을 현재 설정에 반영합니다. 산을 만든 뒤 호수를 추가하거나, 호수의 크기만 바꾸거나, 특정 도형을 이동·회전·삭제하는 편집을 개선했습니다. 타일별 설정과 이미지 지형을 되돌리기·프리셋 저장에 함께 포함합니다.

예를 들어 다음처럼 차례로 요청할 수 있습니다.

1. “북쪽에 산맥을 만들고 중앙에는 큰 호수를 넣어줘.”
2. “산맥은 그대로 두고 호수만 조금 작게 해줘.”
3. “그 호수를 오른쪽으로 조금 옮겨줘.”
4. “고대 위협 밀도를 1.8로 설정해줘.”

실제 변경 내용과 실패 안내도 정비했습니다. 잘못된 AI 응답은 적용하지 않고, 취소한 요청의 늦은 응답이 나중에 설정을 덮어쓰지 않도록 처리합니다. 요청 해석은 선택한 모델과 표현에 따라 달라질 수 있으므로 결과는 미리보기에서 확인합니다.

### 정확한 도형과 자연스러운 윤곽 선택

산을 관통하는 마른 통로도 폭과 방향을 지정할 수 있습니다. 예: “왼쪽 산맥 중앙을 동서로 관통하는, 맵 높이의 8% 폭인 협곡 통로를 만들어줘. 다른 산과 호수는 유지해.” 통로는 흙 바닥으로 산을 깎으며, 물길을 원한다면 물이나 운하를 명시합니다. 해자의 물을 용암으로 바꿀 때는 “모양·섬·폐허는 그대로 두고 재료만 바꿔줘”처럼 요청합니다. [D04/F03 수정과 재현 검증](analysis/2026-09-14-manual-fixes/report.md)을 따로 기록했습니다.

**“원형 호수”는 정확한 원형으로, “자연스러운 원형 호수”는 물가가 울퉁불퉁한 원형으로 요청할 수 있습니다.** 별·하트 등 다른 도형에도 같은 표현을 쓸 수 있습니다. 자연스러운 원형이라고 해서 가운데가 빈 도넛을 만들지는 않습니다.

- “중앙에 원형 호수를 만들어줘.”
- “그 호수의 위치와 크기는 그대로 두고, 윤곽만 자연스럽게 바꿔줘.”
- “살짝 울퉁불퉁하게 해줘.” / “많이 울퉁불퉁하게 해줘.”
- “다시 완전히 정확한 원형으로 돌려줘.”
- “오른쪽 위에 자연스러운 별 모양 호수를 추가해줘.”

윤곽 선택은 되돌리기·프리셋·저장에 포함됩니다. 같은 도형을 다시 생성하거나 이동해도 굴곡을 매번 새로 뽑지 않습니다. 자연스러움은 원래 형태를 알아볼 수 있을 정도의 경계 변형이며, 아주 좁은 통로나 작은 홈은 맵의 칸 크기에 영향을 받습니다. 기존 일반 호수·도넛 생성 방식에 들어 있던 불규칙한 물가는 그대로 유지합니다.

### 월드 지리를 유지하는 특징 추가·제거

**주변 바다·호수와 강의 연결은 유지하고, 타일 내부의 특징을 편집합니다.** Odyssey와 설치된 Vanilla Landmarks Expanded의 실제 특징 정의를 읽어 현재 타일에서 가능한 항목을 판단합니다.

| 요청 | 처리 |
|---|---|
| “삼각주로 바꿔줘.” | 강과 바다·월드 호수 하구가 있는 타일에서 허용 |
| “삼각주만 없애줘.” | 일반 강과 해안을 유지 |
| “합류점을 만들어줘.” | 실제 월드 강 연결 수와 흐름 조건에 맞을 때 허용 |
| “내륙에 해안을 만들어줘.” | 거절하고 이유 안내 |
| “호수 지형 특징을 추가해줘.” | 해당 특징의 조건에 맞으면 내륙에서도 허용 |
| “사막에 오아시스를 추가해줘.” | 바이옴·온도 등 오아시스 조건에 맞으면 허용 |
| “분화구 호수를 추가해줘.” | 제공 모드가 설치되어 있고 평지·내륙 등 그 특징의 조건에 맞으면 허용 |
| “강 방향 / 해안 방향을 바꿔줘.” | 원래 해당 연결이 있는 타일에서 허용 |
| “피오르드만 없애줘.” | 일반 해안을 유지 |
| “강 / 해안을 완전히 없애줘.” | 월드 연결 보존 정책에 따라 거절 |

조건은 바이옴 허용·제외 목록, 언덕, 온도, 오염도, 식생·동물 조건, 강·도로 유무, 해안 접면 수 및 해당 특징의 생성기 검사를 사용합니다. 생성 확률이나 월드 랜드마크 추첨 여부는 수동 편집을 막는 조건으로 사용하지 않습니다. 기본 온천은 스스로 물과 주변 암반을 만들므로 직접 추가할 때 평지·자연발생 바이옴 목록에 제한받지 않습니다. 강·해안과 충돌하는 온천 추가는 여전히 제한합니다.

**모드 특징은 현재 활성화된 모드에서 자동으로 읽습니다.** Vanilla Landmarks Expanded와 필수 선행 모드 Vanilla Expanded Framework를 활성화한 뒤 재시작하면 비옥한 화산 토양·비옥한 비·별 보기 좋은 곳·빈번한 오로라·overgrown도 목록에 포함됩니다. 온천과 화창함은 Odyssey 기능입니다. 설치만 하고 활성화하지 않은 모드의 특징은 사용할 수 없습니다. 비옥한 화산 토양은 맵 특징 전체를 추가하거나, 그 모드의 실제 토양 재료로 특정 영역만 채우도록 요청할 수 있습니다. 날씨·사건 관련 특징을 추가해도 그 효과가 매 순간 발생하는 것은 아닙니다.

AI가 설명을 일반 문장으로 보내면 같은 요청의 응답 형식만 한 번 다시 요청합니다. 형식이 계속 잘못되면 설정을 변경하지 않고 실패를 알립니다. 이 재요청은 API를 추가로 사용하며, 빠진 모드나 맞지 않는 타일 조건을 해결하는 기능은 아닙니다.

조건에 맞지 않으면 이유를 안내하고 **응답 전체를 적용하지 않습니다.** 다른 지형으로 몰래 대체하지 않습니다. 내부 특징은 이름별 제거·복원, 종류별 제거·복원, 되돌리기와 프리셋을 지원하며, 프리셋도 현재 타일의 조건을 검사합니다.

대안을 고를 때도 현재 특징과의 조합을 검사합니다. AI에는 **현재 특징을 유지하며 추가 가능 / 기존 특징 교체 필요 / 현재 조건에서 불가**를 구분해 전달합니다. 예를 들어 온천이 있으면 연못 특징을 단순 추가 대안으로 취급하지 않습니다. 온천을 유지한 물·모래 도형 추가와, 온천을 연못 특징으로 교체하는 것은 서로 다른 선택입니다. 여러 대안 뒤의 “그래”는 어느 쪽인지 다시 확인하도록 안내합니다.

변경 명령은 실제 적용과 같은 검증 경로에서 먼저 검사합니다. 잘못된 명령이면 설정을 유지한 채 AI에게 한 번 설명을 다시 요청합니다. 이 단계에서는 설명만 받으며, AI가 대신 다른 수정안을 보내면 적용하지 않습니다. 추가 API 호출이 발생할 수 있고, 설명의 표현이나 모든 요청 의도까지 자동 검증하는 것은 아닙니다.

이전 개발판은 강·해안을 통째로 생성에서 제외할 수 있었으나, 이번 사용자 결정에 따라 그 기능은 제한했습니다. 이미 저장된 전체 제외 설정은 타일을 열거나 새 맵을 생성할 때 연결 보존 방식으로 자동 전환하며 로그에 남깁니다. 과거 제외 프리셋을 새로 적용할 때에는 조건 오류로 안내합니다.

편집은 선택한 타일의 새 정착지 맵 생성과 실제 지형 특징 목록에 적용됩니다. 이미 플레이 중인 맵을 즉석에서 수정하거나, 월드 랜드마크의 이름·아이콘을 새로 배치하는 기능은 아닙니다. 직접 만든 물 도형은 특징 목록과 별개로 수정합니다. 모든 외부 모드 조합과 모든 특징의 완성된 생성 결과까지 검증한 것은 아닙니다.

### 실제 용암과 다른 지형 재료로 채우기

- “중앙에 평평한 흙 섬을 만들고 주변을 도넛 모양의 실제 용암으로 채워줘.”
- “그 용암 경계를 자연스럽게 해줘.”
- “물로 된 해자의 모양은 그대로 두고 재료만 용암으로 바꿔줘.”
- “그 영역을 식은 용암 / 화산암 / 자갈로 바꿔줘.”

용암은 Odyssey의 **깊은 용암**을 사용합니다. 색만 비슷한 물이 아닙니다. DLC·모드가 실제로 제공하는 영구 지형 재료를 읽어 사용하며, 없는 재료는 다른 것으로 대체하지 않습니다. 식는 임시 지형인 **얕은 용암**은 현재 채움 대상에서 제외합니다. 기존 강·바다·도로와 겹치는 칸은 연결을 유지하고 제외한 칸 수를 안내합니다.

### 기존 영역의 일부만 채우기

“도넛 모양 산을 만들어줘” 다음에 “도넛 안에 70%만 비옥한 토양으로 채워줘”처럼 요청할 수 있습니다. **실제로 채울 수 있는 내부 칸 중 70%**를 채우며 나머지는 원래 지형으로 남깁니다. 산비탈·막힌 바위·건물·월드 강·바다·도로 등 보호할 칸은 계산에서 제외합니다. 칸 단위 반올림으로 아주 작은 차이가 날 수 있습니다.

- “산은 그대로 두고, 안쪽 비옥한 토양만 50%로 줄여줘.”
- “그 영역의 왼쪽부터 70%만 채워줘.”
- “도넛 산을 오른쪽으로 옮겨줘.” — 연결된 채움도 기준 영역을 따라갑니다.

일반 도형 자체의 내부와, 닫힌 고리가 둘러싼 구멍을 구별합니다. 닫힌 내부가 없으면 실패를 안내합니다. 기존 지형에 이미 있는 같은 재료도 비율에 포함하며, 그것만으로 요청 비율을 넘으면 남는 부분을 어떤 재료로 바꿀지 지정하도록 안내합니다. 폐허·건물이 차지하는 칸을 보존하고 남은 땅의 비율을 다시 맞춥니다. 여러 채움이 겹치는 경우와 임의 외부 모드의 뒤늦은 지형 변경까지 모두 검증한 것은 아닙니다.

### 영역이나 위치를 지정해 폐허 배치하기

- “그 섬 안에 벽과 바닥이 남은 작은 폐허를 두 개 놓아줘.”
- “북동쪽에 작은 폐허를 하나 배치해줘.”
- “폐허 개수만 하나로 줄여줘.”
- “섬을 오른쪽으로 옮기고 연결한 폐허도 그 섬 안에 따라오게 해줘.”
- “섬과 거기에 연결한 폐허를 함께 삭제해줘.”

단순 폐허는 **손상된 화강암 벽과 바닥**으로 만듭니다. 지붕·동면관·전리품 등을 포함하는 게임 기본 고대 위협은 아래의 별도 요청으로 배치합니다. 기존 자연 생성 밀도 조절과 위치 지정은 각각 유지합니다.

건물 전체 면적이 실제 영역 안에 들어가야 합니다. 물·용암·도로·막힌 바위·기존 건물·다른 생성기가 예약한 공간을 피합니다. 공간이 부족하면 위치 지정 폐허는 일부만 생성하지 않고 실패 이유를 표시합니다. 영역을 넓히거나 평탄화하고, 크기나 개수를 줄여 다시 요청할 수 있습니다. 크기는 가로·세로 5~31칸, 계획별 1~8개, 전체 최대 24개입니다.

위치만 지정하면 맵 가로·세로 각각 10% 범위 안에서 가까운 공간을 찾습니다. 도형에 연결하면 그 도형의 실제 내부를 사용합니다. Map Preview에는 벽의 배치 계획을 표시하며, 실제 맵에서는 다른 건물과의 충돌을 다시 검사하므로 최종 위치가 달라질 수 있습니다. 배치 요청은 자연 생성 폐허 밀도를 자동으로 바꾸지 않습니다.

### 강가·산기슭·섬 가장자리 배치

- “강 동쪽과 서쪽에 작은 폐허를 각각 두 개씩 놓고, 건물끼리 최소 18칸 떨어뜨려줘.”
- “산 서쪽 기슭에 폐허 두 개를 놓아줘. 산에서 2~10칸 떨어뜨려줘.”
- “섬 안쪽 가장자리에서 2~5칸 떨어진 곳에 폐허 세 개를 배치해줘.”
- “그 폐허를 90도 회전해줘.”

실제 생성된 지형을 기준으로 가까운 자리를 찾습니다. 거리는 **기준 지형과 가장 가까운 건물 칸 사이**의 거리이며, 건물 전체 면적은 안전한 허용 영역 안에 있어야 합니다. 강·물·산과 동서남북 방향, 섬 안쪽 가장자리를 지원하며, 단순 폐허는 90도 단위로 회전할 수 있습니다. 지정한 기준 지형이 없거나 조건을 만족할 공간이 없으면 이유를 안내합니다.

간격은 건물 사이 **최소 빈칸 수**입니다. 정확히 같은 간격으로 줄을 맞추거나 곡선을 따라 방향이 자동 회전하는 기능은 아닙니다. 양쪽에 같은 개수를 원하면 양쪽 계획을 따로 지정합니다.

### 위치를 지정해 게임 기본 고대 위협 생성하기

- “그 섬 안에 가로18 세로18칸짜리 게임 기본 고대 위협 하나를 배치해줘.”
- “산 서쪽 기슭에서 2~12칸 떨어진 곳에 고대 위협을 하나 놓아줘.”
- “배치한 고대 위협은 그대로 두고 자연 생성 고대 위협 밀도만 0.6으로 바꿔줘.”

게임의 기본 고대 위협 생성기를 사용해 건물·지붕과 내부 내용물을 생성합니다. 동면관, 전리품, 경고 장치와 내부 적은 게임의 무작위 생성·DLC·난이도 규칙을 따릅니다. 평화로운 난이도의 비적대 내용물 규칙도 유지하며, 특정 적이나 전리품의 종류·수량을 보장하는 기능은 아닙니다.

크기는 가로·세로 **15~20칸**, 계획별 **1~2개**, 위치 지정 고대 위협은 전체 **최대 4개**입니다. 영역·지형과의 거리·방향·최소 간격은 폐허와 같은 방식으로 지정합니다. 내부 배치의 **회전 지정은 아직 지원하지 않습니다**. 임의 모드의 시설이나 퀘스트 단지를 이 기능으로 대체하지 않습니다.

Map Preview는 고대 위협의 **예약 위치와 크기를 주황색 테두리**로 표시합니다. 내부 내용물은 실제 맵 생성 때 결정하며, 미리보기에서 적이나 동면관을 만들지 않습니다. 배치 공간이 부족하면 위치 지정 구조물 묶음을 생성하기 전에 실패를 표시합니다. 기본 생성기가 실행 중 예상하지 못한 오류를 낸 경우에도 오류를 알리지만, 이미 생성된 개별 물체를 모두 되돌리는 기능까지 보장하지는 않습니다.

### 이미지 기능 일시 중단

이미지 입력 버튼은 화면에서 숨깁니다. PNG/JPEG 가져오기, AI 이미지 해석, 팔레트 적용, 이미지 기반 지형 생성은 현재 사용할 수 없습니다. 예전에 저장한 이미지도 새 맵 생성에 영향을 주지 않습니다. 코드와 저장 데이터는 남겨두었으며, 다시 다루기로 하기 전까지 비활성 상태를 유지합니다.

### 모델 선택 개선

개발판의 Gemini 기본 모델은 **Gemini 3.8 Flash**입니다. 간편 설정에서 **“모델 목록 불러오기”**를 눌러 API에서 조회한 모델을 선택하거나, 모델명을 직접 입력할 수 있습니다. 두 모델로 제한하지 않습니다. 고급 설정의 공급자별 모델 선택과 기존 지정값도 유지합니다.

고급 설정 화면이 깨지던 UI 영역 종료 오류를 수정했습니다. 조회에 실패하면 현재 모델 선택을 유지하고 오류 안내를 표시하며, 목록을 다시 불러올 수 있습니다.

Gemini, OpenAI, OpenRouter 및 OpenAI 호환 로컬 서버 연결을 지원합니다. 모든 공급자·모델에서 같은 품질이 검증된 것은 아닙니다.

## 시작하기

1. **Harmony**, **Map Preview**, **MapGen AI [DEV]**를 활성화합니다. 현재 개발 테스트 패키지는 RimWorld **1.6용**이며, 기존 **MapGen AI**와 DEV 중 사용할 쪽 하나를 활성화합니다.
2. **모드 설정 → MapGen AI**에서 공급자·모델을 선택하고 API 키를 설정합니다. 로컬 모델을 쓰는 경우 서버 주소와 모델을 설정합니다.
3. 월드맵에서 정착할 타일을 선택하고 Map Preview 옆의 **AI Map Gen** 버튼을 엽니다.
4. 원하는 지형을 입력하고 생성 결과를 확인합니다. 이후 대화로 필요한 부분을 수정합니다.

현재는 텍스트 요청을 사용합니다. 이미지 버튼도 화면에서 숨깁니다. 다시 이미지 테스트를 진행할 때 복원할 수 있도록 내부 코드는 보관합니다.

## 현재 범위와 한계

- 재료는 활성화된 콘텐츠의 직접 채울 수 있는 영구 지형에 한합니다. 바다·월드 강·다리·건축 바닥·임시 지형에는 별도 생성 규칙이 필요합니다.
- 위치 지정 폐허·고대 위협과 자연 생성 밀도 조절은 서로 다른 기능입니다. 다른 종류의 구조물은 생성기를 추가하고 검증해야 합니다.
- 도형을 제거해도 그곳이 반드시 빈 흙이 되는 것은 아닙니다. 해당 도형의 생성 명령을 제거하면 원래 지형이 다시 나타납니다.
- 이미지 기능은 일시 중단입니다. 이미지 품질 개선이나 재활성화를 이번 텍스트 작업에 포함하지 않습니다.
- 현재 DEV는 개발·검증 중입니다. 전체 모드 조합, 오래된 실제 세이브, RimWorld 1.5, 모든 모델·언어의 새 기능은 검증하지 않았습니다. 새 프리셋을 이전 버전에서 읽는 것도 보장하지 않습니다.
- 새 위치 지정·실패 안내는 한국어·영어를 우선 제공합니다.

## 추천 선택과 오아시스 같은 지형

“이 타일에 어울리는 지형 추천해 줘”라고 요청하면 현재 바이옴·산악도·강·해안·기존 특징에 맞는 구성을 제안하도록 안내합니다. 고정된 맵 세트를 꺼내는 방식은 아닙니다. 일반 추천은 넓고 연결된 정착 공간을 우선하고, 평지는 대체로 열린 땅을 살리며, 산악은 골짜기나 정착 공간을 확보하도록 합니다. 기하학적인 고리 산이나 좁은 협곡은 직접 요청할 수 있습니다. 이미 지형을 만들었다면 그 맵에 어울리는 추가 요소나 작은 편집을 추천하고 기존 구성은 보존하도록 안내합니다. 현재 한 번에 최대3개를 지원하며 기본은3개, “두 개만 추천해 줘” 같은 요청도 가능합니다. “토양만 추천해 줘”처럼 범위를 좁힐 수도 있습니다. 추천의 다양성·미관·정착 적합성은 모델 지침으로, 모든 응답에 대한 보장은 아닙니다.

각 후보를 현재 타일·기존 특징과 함께 적용할 수 있는지 검사하고, 동일한 설정 결과를 만드는 중복 후보는 다시 요청합니다. 추천을 받으면 **후보별 지도 미리보기가 자동으로 표시**됩니다. 로컬 Map Preview가 순서대로 그리므로 이미지 생성 API나 추가 LLM 토큰은 사용하지 않습니다. 작은 지도를 누르면 확대해서 비교할 수 있습니다.

선택 전에는 맵을 바꾸지 않습니다. `1번`처럼 입력하거나 **1번 적용** 버튼을 누르면 저장된 설정을 적용하며, 이때도 모델에 다시 요청하지 않습니다. 추천이 여러 개일 때 “그래”라고만 하면 번호를 확인합니다. 하나뿐이면 그대로 적용합니다. 되돌리기·초기화·다른 편집 또는 맵 시드·크기 변경 후에는 예전 추천을 사용하지 않습니다. 미리보기 하나가 실패하더라도 다른 후보를 확인하거나 설명을 보고 선택할 수 있습니다.

선택하기 전에 **“3번 통로만 자연스럽게 해 줘”**, **“1번에 비옥도를 조금 높여줘”**처럼 후보를 수정할 수 있습니다. 지정한 후보의 지도만 다시 그리고 다른 후보는 그대로 유지합니다. 여러 번 수정해도 최종 선택 전에는 실제 맵이 바뀌지 않으며, 선택 후에는 되돌리기 한 번으로 선택 전 상태로 돌아갑니다. 수정 요청 해석에는 모델 호출이 필요하고, 지도 재표시에는 추가 모델 호출이 없습니다. 후보 대신 실제 맵을 바로 편집하려면 “추천 말고 현재 맵에 바로 …”라고 명시할 수 있습니다. 후보당 최대32번 수정하며 이후에는 선택하거나 새 추천을 요청합니다. [후보 수정 사용 예시](analysis/2026-09-19-candidate-refinement/manual-tests.md).

미리보기는 지형과 배치를 비교하기 위한 이미지입니다. 식물, 건물 내부, 적·전리품 및 다른 모드의 후반 생성 결과까지 완전히 보여 주지는 않습니다. 생성 시간은 맵 크기와 활성 모드에 따라 달라집니다. 기존 **이미지 업로드·해석 기능은 계속 중단**되어 있으며, 추천 지도 표시와는 별개입니다.

오아시스 **특징**은 원래 바이옴 조건을 따릅니다. 대신 오아시스 **같은 지형**을 요청하면 기존 바이옴과 특징을 유지하면서 작은 불규칙 물웅덩이와 주변 비옥한 토양을 조합하도록 안내합니다. 물만 넣거나 연못 특징과 별도 물웅덩이를 중복 추가하지 않도록 했습니다. 구체적인 크기·배치는 모델 해석에 따라 달라지며 특정 식물 배치를 보장하지 않습니다.

추천과 적용 결과는 **게임에 표시되는 특징·재료 이름과 설명**을 사용합니다. 내부 영문 코드나 도형 ID 대신 “지열로 데워진 온수 샘”, “가장자리가 높고 중앙이 낮은 분지”, “토양의 비옥도를 높입니다”처럼 효과를 설명합니다. 설치된 외부 모드의 번역도 자동으로 사용합니다. 모드가 번역이나 설명을 제공하지 않는 항목은 제공된 원문/이름을 사용합니다. [표시 개선 검증](analysis/2026-09-15-readable-choices/report.md).

추천 검사는 설정의 유효성 검사입니다. 실제 구조물 배치와 지형의 시각적 품질은 맵 생성 결과에서 확인해야 합니다. [검증 기록](analysis/2026-09-15-recommendations/report.md).
